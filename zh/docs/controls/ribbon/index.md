# Ribbon


`RibbonControl` 允许您创建一个受 Microsoft Office 应用程序启发的 Ribbon 界面。该控件支持两种视图——经典视图和简化视图，分别将元素排列为三行和一行。用户可以通过专门的视图选择按钮在两者之间切换。

![ribbon](../../images/ribbon.png)

Ribbon 控件的主要功能包括：

- 经典视图和简化视图
- 支持[传统菜单](../toolbars-and-menus/index.md)中提供的所有类型的元素（命令）：常规按钮、复选按钮、编辑器、标签、子菜单和按钮组
- 内嵌和下拉式元素库（gallery）
- 快速访问工具栏——用户可以在运行时通过上下文菜单将常用命令添加到此工具栏
- 自定义快速访问工具栏的位置（在 Ribbon 命令面板上方或下方）及其可见性
- 在页面标题区域显示元素
- 页面标题着色（可以突出显示上下文选项卡）
- 使用键盘导航 Ribbon 元素
- 组和元素的自适应布局（在 Ribbon 控件宽度变化时调整命令的布局并更改 Ribbon 元素的显示大小）
