# Docking 界面

**Dock Manager** 组件是 Eremex Avalonia UI Controls 库的一部分,可用于实现在众多流行 IDE 中常见的经典 Docking 界面。您可以创建支持停靠(dock)、自动隐藏(auto-hide)和浮动(float)操作的工具面板。特殊的 Document 容器用于显示窗口的主要内容。您可以创建多个 Document,并将它们组织为带选项卡的界面。

![docking-ui](../../images/docking-ui.png)

Docking 库的主要功能包括:

- 灵感来自 Visual Studio IDE 的界面
- 文档切换器(Document Switcher)
- 可停靠的工具面板
- 浮动面板
- 面板自动隐藏功能
- 运行时的布局自定义
- 支持 Document(用于显示窗口主要内容的特殊容器)
- 带选项卡的界面
- 内置上下文命令
- MVVM 支持
- 序列化与反序列化机制
