# 保存和恢复布局 {#save-and-restore-the-layout}

TreeList 允许您保存其列的布局，然后在以后恢复。使用 [`TreeListControl.SaveLayout`](../../API/Eremex.AvaloniaUI.Controls.TreeList/TreeListControl/SaveLayout.md) 和 [`TreeListControl.RestoreLayout`](../../API/Eremex.AvaloniaUI.Controls.TreeList/TreeListControl/RestoreLayout.md) 方法进行布局的序列化和反序列化。
