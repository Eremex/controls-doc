# 保存和恢复布局 {#save-and-restore-the-layout}

DataGrid 允许您保存网格列的布局，并在之后将其恢复。使用 [`DataGridControl.SaveLayout`](../../API/Eremex.AvaloniaUI.Controls.DataGrid/DataGridControl/SaveLayout.md) 和 [`DataGridControl.RestoreLayout`](../../API/Eremex.AvaloniaUI.Controls.DataGrid/DataGridControl/RestoreLayout.md) 方法进行布局的序列化和反序列化。
