## 值

| 名称 | 值 | 说明 |
| --- | --- | --- |
| Default | `0` | 在 Stretch 布局中使用 [`TabSize`](./MxTabControl/TabSize.md)，在其他布局中使用标题内容的大小。 |
| Explicit | `1` | 在所有布局中使用 [`TabSize`](./MxTabControl/TabSize.md)（受项大小约束限制）。 |
| Content | `2` | 使用每个完整选项卡标题的原始大小。 |
| LargestContent | `3` | 使用选项卡条中所有可见选项卡标题的最大原始大小。 |
