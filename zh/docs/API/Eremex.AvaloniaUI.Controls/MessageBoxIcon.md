# MessageBoxIcon 枚举

显示在消息框文本旁边、指示消息严重程度的图标。

## 值

| 名称 | 值 | 说明 |
| --- | --- | --- |
| None | `0` | 无图标。消息框仅显示文本。 |
| Error | `16` | 错误图标，用于已失败的操作。 |
| Hand | `16` | 与 Error 相同的图标，使用其 Windows Forms 名称。 |
| Stop | `16` | 与 Error 相同的图标，使用其 Windows Forms 名称。 |
| Question | `32` | 问号图标，用于向用户提出的问题。 |
| Warning | `48` | 警告图标，用于需要注意但尚未失败的情况。 |
| Exclamation | `48` | 与 Warning 相同的图标，使用其 Windows Forms 名称。 |
| Information | `64` | 信息图标，用于仅向用户提供信息的消息。 |
| Asterisk | `64` | 与 Information 相同的图标，使用其 Windows Forms 名称。 |

## 备注

多个名称共享相同的值，因此共享相同的图标：Error、Hand 和 Stop；Warning 和 Exclamation；Information 和 Asterisk。这些重复名称的存在是为了让从 Windows Forms 移植的代码能够继续编译。
