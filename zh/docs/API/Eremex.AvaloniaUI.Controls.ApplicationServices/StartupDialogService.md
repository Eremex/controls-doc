# StartupDialogService 类

IStartupDialogService 的默认实现。它像 [`DialogService`](./DialogService.md) 一样将视图模型承载在 [`DialogWindow`](./DialogWindow.md) 中，但允许没有所有者窗口：在应用程序启动期间、尚无任何窗口时，它以非模态方式显示对话框，并运行本地事件循环直到其关闭，因此仍会返回结果。
