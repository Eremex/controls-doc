public DialogButtonViewModel(string caption, ICommand command, object? commandParameter,

## 参数

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| caption | `string` | 按钮上显示的文本。 |
| command | `ICommand` | 按下按钮时调用的命令。 |
| commandParameter | `object?` | 传递给 *command* 的值。 |
| classes | `string?` | 应用于按钮的样式类（以空格分隔）。 |
| isDefault | `bool` | `true` 表示将其设为由 Enter 键激活的默认按钮。 |

| dockType | `DockType` | 按钮停靠到的对话框底部区域的一侧。 |
| index | `int?` | 在停靠到同一侧的按钮中的位置，按升序排列。`null` 保持声明顺序。 |
| buttonType | `DialogButtonType` | 是呈现为普通按钮还是复选框。 |
