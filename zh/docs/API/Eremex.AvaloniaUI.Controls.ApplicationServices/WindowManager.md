# WindowManager 类

IWindowsManager 的默认实现。它跟踪窗口激活以了解哪个窗口处于活动状态，并禁用模态对话框后面的窗口，使用户只能与对话框交互；在 Windows 和 X11 上，如果有可用的平台机制，则使用该机制。
