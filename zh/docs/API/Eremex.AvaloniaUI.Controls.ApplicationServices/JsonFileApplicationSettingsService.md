## 备注

该文件为 `settings.json`，位于以入口程序集命名的文件夹中：在 Windows 上位于 `%AppData%` 内，在 macOS 上位于 `~/Library/Application Support` 内，在 Linux 上位于 `$XDG_CONFIG_HOME`（默认为 `~/.config`）内。文件在首次使用时读取，并在每次更改后重写。缺失、无法读取或已损坏的文件会被视为空文件，写入失败也绝不会引发异常：在会话的其余时间里，这些值仍可在内存中使用。
