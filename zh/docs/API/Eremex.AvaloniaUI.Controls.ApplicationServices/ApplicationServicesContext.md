# ApplicationServicesContext 类

对应用程序服务的环境访问及其组成的描述。

该类不依赖任何特定的 DI 容器：唯一的集成类型是 BCL 中的 IServiceProvider。服务组成由 [`RegisterApplicationServices`](./ApplicationServicesContext/RegisterApplicationServices.md) 描述，而生存期和注册方式由宿主选择。

[`Current`](./ApplicationServicesContext/Current.md) 仅用于构造函数注入无法触及的地方：标记扩展、附加属性、转换器以及没有容器的代码隐藏。库服务本身通过构造函数获取依赖项，从不访问环境上下文。
