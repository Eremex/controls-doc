# IConfirmDialogService.Show 方法（1/2）

显示对话框，除非用户已要求不再显示。

**程序集：** `Eremex.Common.Contracts.dll`  
**NuGet 包：** [Eremex.Common.Contracts](https://www.nuget.org/packages/Eremex.Common.Contracts)

## 声明

```csharp
public DialogResult Show(string key, IEnumerable<string> messages, string title, 
    string? header = null, MessageBoxIcon icon = MessageBoxIcon.None, 
    MessageBoxButtons buttons = MessageBoxButtons.OkCancel)
```

## 参数

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| key | `string` | 标识对话框。具有相同键的对话框会一起被抑制，因此请为每条消息使用不同的键。 |
| messages | `IEnumerable<string>` | 显示在对话框正文中的消息行。 |
| title | `string` | 窗口标题。 |
| header | `string?` | 消息上方的强调行，或为 `null`。 |
| icon | [`MessageBoxIcon`](../../Eremex.AvaloniaUI.Controls/MessageBoxIcon.md) | 显示在消息旁边的图标。 |
| buttons | [`MessageBoxButtons`](../../Eremex.AvaloniaUI.Controls/MessageBoxButtons.md) | 页脚中提供的按钮集合。 |

## 返回值

| 类型 | 说明 |
| --- | --- |
| [`DialogResult`](../DialogResult.md) | 所按按钮的结果；如果对话框被抑制，则为记住的结果。 |

## 备注

仅当用户使用 Cancel 以外的按钮作答时才会保存“不再显示”的选择，因此取消对话框永远不会使其不再显示。

public DialogResult Show<TViewModel>(string key, TViewModel content, string title, 
    MessageBoxButtons buttons = MessageBoxButtons.OkCancel)
