# DialogWindow 类

承载通过 IDialogService 或 IWindowService 显示的 ViewModel 的窗口。它在主体中呈现 Content，在底部呈现 ButtonsSource 中的按钮，并根据内容调整自身大小。该窗口由服务为您创建；通常没有理由直接实例化它。

## 备注

正文有两种布局。纯内容，或窗口带有 Message 类时的任意内容，会按消息方式布局：带内边距、文本自动换行、宽度受限，高度过大时可滚动。否则，视图（任何 Control 内容）按原样填充正文，以窗口的 Padding 作为边距，不滚动、不换行、不限制宽度，符合带有自身布局的完整对话框视图的预期。
