## 备注

旨在直接绑定到选择器（功能区库、组合框、菜单）：为 [`SelectedThemeVariant`](./IAppearanceService/SelectedThemeVariant.md) 或 [`SelectedPalette`](./IAppearanceService/SelectedPalette.md) 赋值会立即应用更改，因此 ViewModel 除了公开此服务之外无需编写任何代码。

存在哪些调色板和密度取决于所使用的主题；两者都不提供的主题只会报告空的 [`Palettes`](./IAppearanceService/Palettes.md) 和 [`Densities`](./IAppearanceService/Densities.md) 列表。
