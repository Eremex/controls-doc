# DialogService.ShowDialog&lt;T&gt; 方法（2/2）

在指定窗口上方显示模态对话框。未指定所有者时，使用应用程序的活动窗口。

**命名空间：** [`Eremex.AvaloniaUI.Controls.ApplicationServices`](../index.md)  
**程序集：** `Eremex.Avalonia.Controls.ApplicationServices.dll`  
**NuGet 包：** [Eremex.Avalonia.Controls.ApplicationServices](https://www.nuget.org/packages/Eremex.Avalonia.Controls.ApplicationServices)

## 声明

```csharp
public DialogResult ShowDialog<T>(T viewModel, string? caption, Window? owner)
    where T : IDialogAwareViewModel
```

## 类型参数

| 名称 | 说明 |
| --- | --- |
| T | 驱动对话框的 ViewModel 的类型。 |

## 参数

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| viewModel | `T` | 要显示的 ViewModel。它提供对话框的内容和按钮，并在对话框关闭之前一直附加到窗口。 |
| caption | `string?` | 窗口标题。为 `null` 时，标题取自 Title。 |
| owner | `Window?` | 在其上方显示对话框的窗口。为 `null` 时，使用应用程序的活动窗口。 |

## 返回值

| 类型 | 说明 |
| --- | --- |
| `DialogResult` | 关闭对话框时所用的按钮；如果用户通过窗口标题栏按钮关闭了对话框，则为 None。 |

## 异常

| 异常 | 条件 |
| --- | --- |
| ArgumentNullException | *viewModel* 为 `null`。 |
