# SplashScreenService 类

ISplashScreenService 的默认实现。它显示由 [`SplashScreenViewModel`](./SplashScreenViewModel.md) 驱动的通用 [`SplashScreen`](./SplashScreen.md) 窗口。应用程序通过派生此服务并重写 CreateViewModel 以返回已配置（也可以是派生的）视图模型来添加自己的品牌。
