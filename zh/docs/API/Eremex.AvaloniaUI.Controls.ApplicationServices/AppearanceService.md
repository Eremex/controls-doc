## 备注

变体始终可用。调色板和密度来自正在使用的主题：使用 DeltaDesign 主题时，会提供其所有调色板和密度；使用不包含这些内容的主题时，相应列表为空，设置所选项不会产生任何效果。

这些列表在首次使用时构建，而不是在构造函数中构建，因此可以在应用程序样式存在之前注册该服务。
