# IWindowAwareViewModel 接口

由在自己的窗口中显示的 ViewModel 实现。窗口服务在显示窗口之前调用 [`Attach`](./IWindowAwareViewModel/Attach.md)，在窗口关闭之后调用 [`Detach`](./IWindowAwareViewModel/Detach.md)，这使 ViewModel 能够观察其窗口而不依赖任何窗口类型。

**程序集：** `Eremex.Common.Contracts.dll`
