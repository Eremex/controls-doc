# ViewLocatorAttribute 类

应用于 ViewModel，用于声明由哪个 View 呈现它以及承载窗口应具有何种外观。窗口服务在显示 ViewModel 时读取此特性，创建 View 并将其放入 [`Content`](./IWindowAwareViewModel/Content.md)，因此 ViewModel 永远无需自行构造 View。
