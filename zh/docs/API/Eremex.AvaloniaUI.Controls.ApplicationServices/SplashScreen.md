# SplashScreen 类

由 [`SplashScreenService`](./SplashScreenService.md) 显示的通用、不含品牌信息的启动画面窗口。它绑定到 [`SplashScreenViewModel`](./SplashScreenViewModel.md)，并绘制其背景图像和文本行；应用程序通过提供派生的视图模型对其进行自定义。
