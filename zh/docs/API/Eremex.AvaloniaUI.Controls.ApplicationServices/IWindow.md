# IWindow 接口

这些服务所看到的应用程序窗口。ViewModel 从 [`IWindowsManager`](./IWindowsManager.md) 获取窗口，并将其作为所请求对话框的所有者传回，而无需指明 UI 框架的任何窗口类型。

## 备注

此程序集不引用任何 UI 框架，因此窗口不能以其框架类型出现在此处。UI 层通过此接口呈现自己的窗口，并在需要显示对话框时将其解析回来，这与将文件对话框选项转换为平台选择器所需类型的方式相同。
