# IDialogResultWindow 接口

记住其关闭结果的对话框窗口。视图模型通过 [`CloseWithResult`](./IDialogResultWindow/CloseWithResult.md) 关闭其窗口，使结果除了模态显示外，也可从 [`Result`](./IDialogResultWindow/Result.md) 获得；当对话框以非模态方式显示（例如在应用程序启动期间、所有者窗口尚不存在时）这一点很重要。
