# CartesianChart.Scroll 方法

沿值轴移动轴的可见范围。

**命名空间：** [`Eremex.AvaloniaUI.Charts`](../index.md)  
**程序集：** `Eremex.Avalonia.Charts.dll`  
**NuGet 包：** [Eremex.Avalonia.Controls](https://www.nuget.org/packages/Eremex.Avalonia.Controls)

## 声明

```csharp
public void Scroll(double deltaX, double deltaY, IEnumerable<Axis>? axes = null)
```

## 参数

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| deltaX | `double` | 水平偏移量，以可见范围的比例表示。正值将范围移向更大的 X 值。 |
| deltaY | `double` | 垂直偏移量，以可见范围的比例表示。正值将范围移向更大的 Y 值。 |
| axes | `IEnumerable<Axis>?` | 要滚动的轴。传入 `null` 可滚动图表的所有轴。 |

## 备注

每个偏移量仅应用于方向匹配的轴，因此水平偏移影响水平轴，垂直偏移影响垂直轴。
