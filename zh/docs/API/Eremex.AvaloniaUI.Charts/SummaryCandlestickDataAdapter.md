# SummaryCandlestickDataAdapter 类

将日期和时间参数汇总为 K 线数据点。属于同一度量单位的所有源值生成一根 K 线，其中开盘值和收盘值是该组的第一个值和最后一个值，最低值和最高值是该组的最小值和最大值。
