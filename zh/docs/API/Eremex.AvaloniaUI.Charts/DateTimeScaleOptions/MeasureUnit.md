# DateTimeScaleOptions.MeasureUnit 属性

获取或设置数据值舍入到的日期和时间单位。属于同一单位的值绘制在相同位置，因此系列将它们显示为一个值。例如，当此属性为 Day 时，2026-01-01 10:20 和 2026-01-01 13:40 共享一个位置；当其为 Hour 时，则位于不同位置。

**NuGet 包：** [Eremex.Avalonia.Controls](https://www.nuget.org/packages/Eremex.Avalonia.Controls)

## 备注

此属性设置的是数据本身的粒度，而不是网格线和标签的粒度；网格线和标签请使用 [`GridSpacingUnit`](./GridSpacingUnit.md)。当此属性为 null 时，值将绘制在其精确位置。它还定义十字准线吸附的粒度，并防止网格线绘制得比此单位更细。
