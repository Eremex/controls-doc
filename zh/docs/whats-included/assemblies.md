# 程序集

本主题描述了 Eremex Avalonia UI Controls 库中包含的控件和[主题](../controls/themes/index.md)所属的程序集。



## NuGet 包

Eremex Controls 的程序集和项目模板以 NuGet 包的形式分发。您可以通过以下链接在 [nuget.org](https://www.nuget.org) 网站上找到并下载它们：

- [Eremex Controls at NuGet.org](https://www.nuget.org/profiles/EremexControls)

## 包含的程序集

- **Eremex.Avalonia.Controls** — 包含用于数据整形和编辑的 Eremex 控件，以及通用工具类。该程序集中的主要控件包括：

    - `DataGridControl`
    - `TreeListControl` 和 `TreeViewControl`
    - `PropertyGridControl`
    - `ListViewControl`
    - `CartesianChart`、`PolarChart` 和 `SmithChart`
    - `RibbonControl`
    - `ToolbarManager`
    - `DockManager`
    - `Heatmap`
    - 数据编辑器（`TextEditor`、`ButtonEditor`、`ComboBoxEditor`、`CheckEditor`、`SpinEditor` 等）
    - 实用控件（`MxTabControl`、`MxMessageBox`、`SplitContainerControl`、`CalendarControl` 等）

- **Eremex.Avalonia.Controls3D** — 包含用于在应用程序中渲染 3D 模型的控件和类。
    - `Graphics3DControl` — 该库中的主要控件，可用于显示 3D 模型并与之交互。

- **Eremex.DocumentProcessing** — 一个用于生成 PDF 和 XLSX 文档的非可视化组件库。

- **Eremex.Avalonia.Themes.DeltaDesign** — 包含 Eremex 控件的“DeltaDesign”外观主题。

- **Eremex.Avalonia.Templates** — 包含用于从零开始创建带有 Eremex 控件的新 Avalonia UI 项目的模板。请参阅[项目模板](project-templates.md)。

- **Eremex.Common.Contracts** — 包含无 UI 依赖的模型层通用接口和基类。
