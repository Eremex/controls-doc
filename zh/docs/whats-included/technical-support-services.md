# 技术支持服务

[EMX Support Center](https://sc.eremexcontrols.net) 是提交和管理与 EMX Controls 库相关的技术支持请求的中心枢纽。

我们的目标是帮助您高效地解决技术难题，并以专业、及时的方式交付高质量的软件解决方案。支持团队的工作时间为周一至周五，莫斯科时间（UTC+3）9:00 至 18:00，并致力于在一到两个工作日内响应所有传入的请求。

支持中心向所有人开放。即使不登录，您也可以浏览现有的公开工单。

支持服务以英语和俄语提供。

## 提交工单之前

为节省时间，我们建议您先查阅其他技术资源。许多常见问题已经得到解答。

- [浏览现有工单](https://sc.eremexcontrols.net/issues)
- [文档](https://eremexcontrols.net)
- [演示应用程序](https://github.com/Eremex/controls-demo)

## 提交工单

您必须登录才能创建新的支持工单。授权后，请遵循以下准则：

- 使用英语或俄语。以英语撰写有助于全球用户在工单公开时找到并从中受益。

- 每个工单只处理一个问题或疑问。如果您提交的工单包含多个问题，我们的支持工程师会要求您将其拆分为多个单独的工单。

- 提供清晰的分步说明以重现问题。

- 如果可能，请附上能够展示问题的最小示例项目。

- 请包含完整的堆栈跟踪、屏幕截图和日志文件。

- 您可以将任何工单标记为私有。私有工单仅您本人和我们的支持工程师可见。

## 重要限制

- 我们保留在滥用情况下限制访问支持中心的权利。

- 我们的标准支持计划不包括针对大型项目的定制开发服务或代码审查。如需扩展支持选项，请通过 [controls@eremex.com](mailto:controls@eremex.com) 联系我们。

- 我们不提供基础编程技能或标准软件开发实践方面的教学。

- 对于包含辱骂性或冒犯性语言的工单，我们将不予回复。
