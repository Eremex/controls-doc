# What's Included

The Eremex Avalonia UI Controls library includes a set of assemblies with [controls](../controls/index.md) and [themes](../controls/themes/index.md) distributed as NuGet packages.
The library also provides project templates to help you quickly create new applications from scratch.

## Included Assemblies and Project Templates

The following topics describe the assemblies and project templates that are part of the Eremex Controls library:

- [Assemblies](assemblies.md)
- [Project Templates](project-templates.md)

## Build-time Telemetry

The build-time telemetry feature captures anonymous usage data about development environments where the Eremex Controls library is used. The data you share helps us understand real-world usage scenarios, and enables us to make targeted improvements and deliver a better product.

- [Build-time Telemetry](build-time-telemetry.md)
