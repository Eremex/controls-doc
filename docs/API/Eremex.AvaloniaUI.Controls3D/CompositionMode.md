Lists values that specify how the rendered image is combined with the Avalonia compositor.

## Values

| name | value | description |
| --- | --- | --- |
| Default | `0` | Hardware composition is used on Windows and macOS, and software composition on Linux. |
| Hardware | `1` | The rendered image is shared with the Avalonia compositor through GPU interop. |
| Software | `2` | The rendered image is copied to a bitmap that the control draws during its render pass. |
