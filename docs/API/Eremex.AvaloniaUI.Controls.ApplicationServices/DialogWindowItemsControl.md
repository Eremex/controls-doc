# DialogWindowItemsControl class

The footer of [`DialogWindow`](./DialogWindow.md) that hosts the buttons of ButtonsSource, creating a Button or a CheckBox per ButtonType. It is public so that UI tests can locate a dialog's buttons; there is normally no reason to use it directly.
