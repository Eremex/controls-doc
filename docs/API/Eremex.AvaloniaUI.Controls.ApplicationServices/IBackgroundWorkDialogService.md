# IBackgroundWorkDialogService interface

An [`IDialogService`](./IDialogService.md) dedicated to dialogs that report the progress of a background operation. It behaves like [`IDialogService`](./IDialogService.md) but is a distinct contract, so a progress dialog can be resolved and substituted independently of the ordinary dialogs.
