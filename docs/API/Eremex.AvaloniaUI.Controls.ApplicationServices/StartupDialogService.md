# StartupDialogService class

The default IStartupDialogService implementation. It hosts the view model in a [`DialogWindow`](./DialogWindow.md) like [`DialogService`](./DialogService.md), but tolerates the absence of an owner window: during application startup, before any window exists, it shows the dialog non-modally and pumps a local event loop until it closes, so a result is still returned.
