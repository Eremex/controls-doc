# SplashScreenService class

The default ISplashScreenService implementation. It shows a generic [`SplashScreen`](./SplashScreen.md) window driven by a [`SplashScreenViewModel`](./SplashScreenViewModel.md). An application adds its own branding by deriving from this service and overriding CreateViewModel to return a configured (and possibly derived) view model.
