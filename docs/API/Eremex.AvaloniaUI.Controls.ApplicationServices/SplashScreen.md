# SplashScreen class

The generic, brand-neutral splash window shown by [`SplashScreenService`](./SplashScreenService.md). It binds to a [`SplashScreenViewModel`](./SplashScreenViewModel.md) and draws its background image and text lines; an application customises it by supplying a derived view model.
