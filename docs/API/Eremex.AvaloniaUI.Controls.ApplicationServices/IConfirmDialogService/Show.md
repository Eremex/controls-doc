## Parameters

| name | type | description |
| --- | --- | --- |
| key | `string` | Identifies the dialog. Dialogs with the same key are suppressed together, so use a distinct key for each message. |
| messages | `IEnumerable<string>` | The message lines shown in the body of the dialog. |
| title | `string` | The window caption. |
| header | `string?` | The emphasized line above the messages, or `null`. |
| icon | [`MessageBoxIcon`](../../Eremex.AvaloniaUI.Controls/MessageBoxIcon.md) | The icon shown next to the messages. |
| buttons | [`MessageBoxButtons`](../../Eremex.AvaloniaUI.Controls/MessageBoxButtons.md) | The set of buttons to offer in the footer. |

| type | description |
| --- | --- |
| [`DialogResult`](../DialogResult.md) | The result of the pressed button, or the remembered result when the dialog is suppressed. |

## Remarks

The "Don't show again" choice is stored only when the user answers with a button other than Cancel, so cancelling a dialog never silences it.
