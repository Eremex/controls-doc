# IApplicationSettingsService interface

Stores application settings as values addressed by a key, for example the "do not show again" choices of confirmation dialogs or the last used folder.

## Remarks

The default implementation keeps the values in memory only. An application that wants them to survive a restart registers its own implementation backed by its settings storage. Keys are case-sensitive; use a prefix that identifies the feature, such as `"ConfirmDialog.Suppress.MyKey"`.
