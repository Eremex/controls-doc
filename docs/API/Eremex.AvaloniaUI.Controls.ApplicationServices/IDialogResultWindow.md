# IDialogResultWindow interface

A dialog window that remembers the result it was closed with. A view model closes its window through [`CloseWithResult`](./IDialogResultWindow/CloseWithResult.md) so that the result is available from [`Result`](./IDialogResultWindow/Result.md) as well as from a modal show, which matters when the dialog is shown non-modally (for example during application startup, before an owner window exists).
