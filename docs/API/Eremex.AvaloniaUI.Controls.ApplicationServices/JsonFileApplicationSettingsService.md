## Remarks

The file is `settings.json` in a folder named after the entry assembly, inside `%AppData%` on Windows, `~/Library/Application Support` on macOS and `$XDG_CONFIG_HOME` (`~/.config` by default) on Linux. The file is read on first use and rewritten after every change. A missing, unreadable or corrupt file is treated as empty, and a failure to write never throws: the values stay available in memory for the rest of the session.
