# DateTimeScaleOptions.MeasureUnit property

Gets or sets the date and time unit to which data values are rounded. Values that fall into the same unit are plotted at the same position, so a series shows them as one value. For example, 2026-01-01 10:20 and 2026-01-01 13:40 share one position when this property is Day, and occupy different positions when it is Hour.

## Remarks

This property sets the granularity of the data itself, not of the gridlines and labels; use [`GridSpacingUnit`](./GridSpacingUnit.md) for those. When this property is null, values are plotted at their exact position. It also defines the granularity at which the crosshair snaps, and stops the gridlines from being drawn more finely than this unit.
