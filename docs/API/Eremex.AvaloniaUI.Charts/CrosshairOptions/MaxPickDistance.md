# CrosshairOptions.MaxPickDistance property

Gets or sets the largest distance from the pointer at which a data point is still picked by the crosshair, in device-independent units. Increase this value for sparse series whose points do not sit directly under the pointer.

**Namespace:** [`Eremex.AvaloniaUI.Charts`](../index.md)  
**Assembly:** `Eremex.Avalonia.Charts.dll`  
**NuGet Package:** [Eremex.Avalonia.Controls](https://www.nuget.org/packages/Eremex.Avalonia.Controls)

## Declaration

```csharp
public int MaxPickDistance { get; set; }
```

## Remarks

A value of zero or less removes the limit, so the nearest data point is picked regardless of how far it is from the pointer. This is the default.
