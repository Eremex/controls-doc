# CrosshairOptions.SeriesLabelShowDelay property

Gets or sets how long the crosshair must stay on the same data before the series labels appear, in milliseconds.

## Remarks

The wait starts over each time the crosshair moves to another data point, so increase this value to stop the labels from appearing while the pointer travels across the plot area. A value of zero or less removes the delay, so the series labels appear immediately; this is the default. The delay applies only to the series labels; the argument and value labels on the axes always follow the pointer.
