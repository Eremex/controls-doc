
## Parameters

| name | type | description |
| --- | --- | --- |
| deltaX | `double` | The horizontal shift, expressed as a fraction of the visible range. Positive values move the range toward larger X values. |
| deltaY | `double` | The vertical shift, expressed as a fraction of the visible range. Positive values move the range toward larger Y values. |
| axes | `IEnumerable<Axis>?` | The axes to scroll. Pass `null` to scroll all axes of the chart. |

## Remarks

Each delta is applied only to the axes that run in the matching direction, so the horizontal shift affects the horizontal axes and the vertical shift affects the vertical ones.
