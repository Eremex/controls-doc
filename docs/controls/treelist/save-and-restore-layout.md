# Save and Restore the Layout

Tree List allows you to save the layout of its columns and then restore it later. Use the [`TreeListControl.SaveLayout`](../../API/Eremex.AvaloniaUI.Controls.TreeList/TreeListControl/SaveLayout.md) and [`TreeListControl.RestoreLayout`](../../API/Eremex.AvaloniaUI.Controls.TreeList/TreeListControl/RestoreLayout.md) methods for the layout serialization and deserialization.
