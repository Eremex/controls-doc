# Документация EMX Controls — офлайн-версия

[English](README.md) · **Русский**

Исходники сайта документации библиотеки **Eremex Avalonia UI Controls** (EMX Controls)
на трёх языках: английский, русский (`/ru/`), китайский (`/zh/`).
Репозиторий позволяет развернуть копию сайта **в закрытом контуре без доступа в интернет**:
собранный сайт — это обычные статические файлы, шрифты, поиск и картинки лежат внутри,
внешние CDN и аналитика не используются.

Официальный сайт: <https://eremexcontrols.net/>

## Самый быстрый способ: готовый архив

1. На машине с интернетом откройте раздел **Releases** этого репозитория и скачайте `emx-docs-offline.zip`
   (или возьмите артефакт последней сборки во вкладке **Actions**).
2. Перенесите архив в закрытый контур и распакуйте.
3. Установите Python 3.8+ и запустите:

   ```bash
   python serve.py
   ```

4. Откройте <http://127.0.0.1:8080/> (русская версия — `/ru/`, китайская — `/zh/`).

Чтобы сайт был доступен коллегам по сети:

```bash
python serve.py --host 0.0.0.0 --port 8080
```

Вместо `serve.py` можно отдавать папку `site/` любым веб-сервером — nginx, Apache, IIS, Caddy:
достаточно раздавать её как статику из корня сайта.

> **Важно.** Сайт собран штатным [Zensical](https://zensical.org/) в *offline-режиме*: все ссылки относительные,
> поэтому он работает из любой папки и из любого подкаталога URL (например, `https://intranet/docs/`).
> Страницы можно открыть и просто с диска (`site/index.html`), но браузеры блокируют загрузку поискового индекса
> по `file://`, так что для работы поиска запускайте веб-сервер (достаточно `serve.py`).

## Собрать самому из исходников

Требуется Python 3.10+ (на машине сборки нужен интернет для установки зависимостей — см. ниже про полностью офлайн-сборку).

```bash
python build.py            # создаёт .venv, ставит зависимости, собирает сайт в site/
python build.py --package  # то же + dist/emx-docs-offline.zip (сайт + serve.py)
python build.py --serve    # собрать и сразу запустить на http://127.0.0.1:8080
python serve.py            # запустить уже собранный сайт
```

Это просто три запуска штатного Zensical в offline-режиме (`OFFLINE=true zensical build`, по одному на язык;
русская и китайская версии оказываются в `site/ru` и `site/zh`). Никаких собственных хуков, плагинов и шаблонов нет,
готовый сайт не обращается к внешним серверам.

### Сборка полностью без интернета

На машине с интернетом и той же ОС/версией Python, что в закрытом контуре:

```bash
pip download -r requirements.in -d wheels
```

Перенесите репозиторий вместе с папкой `wheels` в закрытый контур и выполните:

```bash
python build.py --wheels wheels
```

### Docker

```bash
docker build -t emx-docs .
docker run -d -p 8080:80 emx-docs
```

Образ можно перенести в закрытый контур без реестра:

```bash
docker save emx-docs | gzip > emx-docs.tar.gz      # на машине с интернетом
gunzip -c emx-docs.tar.gz | docker load            # в закрытом контуре
```

Если Docker в контуре есть, а Python нет — проще всего собрать образ снаружи и перенести его.

## Структура репозитория

| Путь | Назначение |
|---|---|
| `docs/`, `ru/docs/`, `zh/docs/` | Markdown-исходники (en / ru / zh) |
| `mkdocs.yml`, `base-mkdocs.yml` (+ в `ru/`, `zh/`) | Навигация и конфигурация сайта |
| `docs/vendor/glightbox/` | Просмотр картинок в увеличенном виде; лежит локально, чтобы тема не грузила его с CDN |
| `build.py`, `serve.py` | Обёртка для сборки и необязательный локальный сервер |
| `requirements.in` | Зависимости Python (только Zensical) |

Сайт собирается генератором [Zensical](https://zensical.org/) (совместим с MkDocs Material).

## Обновление

Репозиторий синхронизируется из закрытого репозитория Eremex, править файлы здесь напрямую
не нужно — изменения будут перезаписаны следующей синхронизацией. Новые версии выходят как релизы (теги `v*`).
