Задаёт расположение заголовков вкладок, когда доступного места недостаточно.

## Значения

| имя | значение | описание |
| --- | --- | --- |
| MultiLine | `0` | Переносит заголовки вкладок на несколько строк. |
| Scroll | `1` | Располагает заголовки вкладок в одну строку и позволяет прокручивать к заголовкам за пределами видимой области. |
