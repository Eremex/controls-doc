# Свойство MxTabControl.TabSize

Возвращает или задаёт предпочтительную длину заголовка вкладки вдоль полосы вкладок в аппаратно-независимых пикселях. Значение должно быть конечным и больше нуля. Используется в режиме Explicit и в режиме Default при размещении Stretch.
