# Свойство MxTabControl.TabHeaderCollapseThreshold

Возвращает или задаёт длину заголовка вкладки в аппаратно-независимых пикселях, при которой или ниже которой текст заменяется доступным глифом. Ноль отключает замену. Значение должно быть конечным и неотрицательным и не влияет на размер вкладки.
