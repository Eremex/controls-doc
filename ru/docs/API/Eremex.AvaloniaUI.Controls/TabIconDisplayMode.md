# Перечисление TabIconDisplayMode

Задаёт, когда отображаются глифы заголовков вкладок.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls`](./index.md)  
**Сборка:** `Eremex.Avalonia.Controls.dll`  
**NuGet-пакет:** [Eremex.Avalonia.Controls](https://www.nuget.org/packages/Eremex.Avalonia.Controls)

## Объявление

```csharp
public enum TabIconDisplayMode
```

## Значения

| имя | значение | описание |
| --- | --- | --- |
| Always | `0` | Отображает доступный глиф и рядом с текстом заголовка, и когда текст скрыт. |
| WhenTextCollapsed | `1` | Отображает доступный глиф, только когда текст заголовка скрыт. |
| Never | `2` | Скрывает глифы и не позволяет заменять текст заголовка глифом. |
