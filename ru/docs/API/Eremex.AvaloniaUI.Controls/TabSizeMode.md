Задаёт способ определения предпочтительного размера заголовка вкладки.

## Значения

| имя | значение | описание |
| --- | --- | --- |
| Default | `0` | Использует [`TabSize`](./MxTabControl/TabSize.md) при размещении Stretch и размер содержимого заголовка при остальных типах размещения. |
| Explicit | `1` | Использует [`TabSize`](./MxTabControl/TabSize.md) при любом размещении с учётом ограничений размера элементов. |
| Content | `2` | Использует собственный размер каждого заголовка вкладки целиком. |
| LargestContent | `3` | Использует наибольший собственный размер заголовка среди всех видимых вкладок полосы. |
