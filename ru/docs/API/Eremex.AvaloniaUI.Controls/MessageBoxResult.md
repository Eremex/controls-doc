# Перечисление MessageBoxResult

Обозначает одну кнопку окна сообщения — как кнопку, нажатую пользователем, так и кнопку, которая должна быть кнопкой по умолчанию.

**Сборка:** `Eremex.Common.Contracts.dll`

## Значения

| имя | значение | описание |
| --- | --- | --- |
| None | `0` | Нет кнопки. Возвращается, если окно сообщения было закрыто без нажатия кнопки, и используется, чтобы указать, что никакая конкретная кнопка не должна быть кнопкой по умолчанию. |
| Ok | `1` | Кнопка OK. |
| Cancel | `2` | Кнопка Cancel. |
| Yes | `3` | Кнопка Yes. |
| No | `4` | Кнопка No. |
| Abort | `5` | Кнопка Abort. |
| Retry | `6` | Кнопка Retry. |
| Ignore | `7` | Кнопка Ignore. |

## Примечания

Сервисы приложения преобразуют это значение в [`DialogResult`](../Eremex.AvaloniaUI.Controls.ApplicationServices/DialogResult.md), которое и возвращает [`IMessageBoxService`](../Eremex.AvaloniaUI.Controls.ApplicationServices/IMessageBoxService.md).
