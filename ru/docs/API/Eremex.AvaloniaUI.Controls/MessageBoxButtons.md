# Перечисление MessageBoxButtons

Набор кнопок, предлагаемых окном сообщения. Каждое значение — это комбинация флагов отдельных кнопок, поэтому кнопки всегда отображаются в стандартном для этой комбинации порядке.

## Значения

| имя | значение | описание |
| --- | --- | --- |
| Ok | `1` | Одна кнопка OK — для сообщения, которое пользователю нужно только подтвердить. |
| OkCancel | `3` | OK и Cancel — для подтверждения или отмены действия. |
| YesNoCancel | `14` | Yes, No и Cancel — для вопроса, на который пользователь может и не отвечать. |

| RetryCancel | `34` | Retry и Cancel — для сбоя, при котором пользователь может либо повторить попытку, либо отказаться. |
