## Значения

| имя | значение | описание |
| --- | --- | --- |
| None | `0` | Без значка. Окно сообщения показывает только текст. |
| Error | `16` | Значок ошибки — для операции, которая завершилась неудачей. |
| Hand | `16` | Тот же значок, что и Error, под именем из Windows Forms. |
| Stop | `16` | Тот же значок, что и Error, под именем из Windows Forms. |
| Question | `32` | Значок вопросительного знака — для вопроса, задаваемого пользователю. |
| Warning | `48` | Значок предупреждения — для ситуации, требующей внимания, но ещё не являющейся сбоем. |
| Exclamation | `48` | Тот же значок, что и Warning, под именем из Windows Forms. |
| Information | `64` | Значок информации — для сообщения, которое просто информирует пользователя. |
| Asterisk | `64` | Тот же значок, что и Information, под именем из Windows Forms. |

## Примечания

Несколько имён имеют одно и то же значение и, следовательно, один и тот же значок: Error, Hand и Stop; Warning и Exclamation; Information и Asterisk. Дубликаты существуют для того, чтобы код, перенесённый из Windows Forms, продолжал компилироваться.
