## Значения

| имя | значение | описание |
| --- | --- | --- |
| Large | `0x1` | Отображает большой глиф с заголовком под ним. |
| Small | `0x2` | Отображает малый глиф рядом с заголовком. |
| SmallGlyph | `0x4` | Отображает только малый глиф. |
