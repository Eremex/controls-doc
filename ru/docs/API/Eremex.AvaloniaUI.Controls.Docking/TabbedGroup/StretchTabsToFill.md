# Свойство TabbedGroup.StretchTabsToFill

Возвращает или задаёт, заполняют ли заголовки вкладок доступное место за счёт добавления одинаковой длины к каждому заголовку с учётом ограничений размера элементов. Применяется к каждой строке в любом режиме размещения.
