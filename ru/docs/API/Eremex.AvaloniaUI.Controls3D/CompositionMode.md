# Перечисление CompositionMode

Перечисляет значения, задающие способ объединения отрисованного изображения с компоновщиком Avalonia.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls3D`](./index.md)  
**Сборка:** `Eremex.Avalonia.Controls3D.dll`

## Значения

| имя | значение | описание |
| --- | --- | --- |
| Default | `0` | В Windows и macOS используется аппаратная компоновка, а в Linux — программная. |
| Hardware | `1` | Отрисованное изображение передаётся компоновщику Avalonia через взаимодействие с GPU. |
| Software | `2` | Отрисованное изображение копируется в растровое изображение, которое контрол отображает во время своего прохода отрисовки. |
