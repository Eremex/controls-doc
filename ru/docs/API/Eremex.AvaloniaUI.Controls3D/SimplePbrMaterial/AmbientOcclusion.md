# Свойство SimplePbrMaterial.AmbientOcclusion

Возвращает или задаёт коэффициент, ослабляющий фоновое освещение на основе изображений, применяемое к поверхности. Значение по умолчанию — единица, при которой фоновое освещение не меняется.
