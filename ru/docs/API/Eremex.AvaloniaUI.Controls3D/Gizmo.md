# Класс Gizmo

Представляет индикатор ориентации, который Graphics3DControl отображает в одном из своих углов, чтобы показать направление камеры родительского контрола. Если у контрола нет собственных моделей, гизмо отображает оси координат с подписями X, Y и Z.
