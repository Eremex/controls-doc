# Перечисление CameraPosition

Перечисляет значения, задающие направление, с которого камера по умолчанию смотрит на сцену.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls3D`](./index.md)  
**Сборка:** `Eremex.Avalonia.Controls3D.dll`  
**NuGet-пакет:** [Eremex.Avalonia.Controls3D](https://www.nuget.org/packages/Eremex.Avalonia.Controls3D)

## Значения

| имя | значение | описание |
| --- | --- | --- |
| Front | `0` | Камера располагается на положительной оси Z и смотрит на начало координат. |
| Rear | `1` | Камера располагается на отрицательной оси Z и смотрит на начало координат. |
| Up | `2` | Камера располагается на положительной оси Y и смотрит на начало координат. |
| Down | `3` | Камера располагается на отрицательной оси Y и смотрит на начало координат. |
| Left | `4` | Камера располагается на отрицательной оси X и смотрит на начало координат. |
| Right | `5` | Камера располагается на положительной оси X и смотрит на начало координат. |
| IsoXYZ | `6` | Камера располагается на диагонали, проходящей через оси X, Y и Z, и смотрит на начало координат. |
