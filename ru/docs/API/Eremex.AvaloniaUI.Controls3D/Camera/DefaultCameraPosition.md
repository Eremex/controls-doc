# Свойство Camera.DefaultCameraPosition

Возвращает или задаёт направление, с которого камера смотрит на сцену. Значение по умолчанию — CameraPosition.IsoXYZ.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls3D`](../index.md)  
**Сборка:** `Eremex.Avalonia.Controls3D.dll`  
**NuGet-пакет:** [Eremex.Avalonia.Controls3D](https://www.nuget.org/packages/Eremex.Avalonia.Controls3D)

## Объявление

```csharp
public CameraPosition DefaultCameraPosition { get; set; }
```

## Примечания

Контрол использует это значение для кадрирования сцены, когда у камеры ещё нет допустимого положения, например при первом отображении сцены.
