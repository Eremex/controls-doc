# Класс Graphics3DCollection&lt;T&gt;

Представляет коллекцию элементов, в которой контрол 3D-графики хранит свои модели, материалы и источники света. Коллекция отражает источник, присвоенный свойству источника элементов её владельца, поэтому элементы, добавленные в этот источник или удалённые из него, сразу появляются в коллекции.
