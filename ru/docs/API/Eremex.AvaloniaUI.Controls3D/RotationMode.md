# Перечисление RotationMode

Перечисляет значения, задающие точку, вокруг которой вращается камера, когда пользователь поворачивает сцену.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls3D`](./index.md)  
**Сборка:** `Eremex.Avalonia.Controls3D.dll`  
**NuGet-пакет:** [Eremex.Avalonia.Controls3D](https://www.nuget.org/packages/Eremex.Avalonia.Controls3D)

## Объявление

```csharp
public enum RotationMode
```

## Значения

| имя | значение | описание |
| --- | --- | --- |
| AroundCameraTarget | `0` | Камера вращается вокруг своей цели. |
| AroundMouseHit | `1` | Камера вращается вокруг точки сцены, которая находилась под указателем мыши в начале вращения. |
