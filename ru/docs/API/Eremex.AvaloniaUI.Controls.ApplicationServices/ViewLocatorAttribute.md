# Класс ViewLocatorAttribute

Применяется к ViewModel, чтобы объявить, какое View её отображает и как должно выглядеть окно, в котором она размещается. Сервисы окон считывают этот атрибут при показе ViewModel, создают View и помещают его в [`Content`](./IWindowAwareViewModel/Content.md), поэтому ViewModel никогда не нужно создавать собственное View.
