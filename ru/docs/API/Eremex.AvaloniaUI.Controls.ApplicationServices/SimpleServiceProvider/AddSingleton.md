# Метод SimpleServiceProvider.AddSingleton&lt;TService&gt; (2 из 2)

Регистрирует готовый экземпляр под типом *TService*. Тип указывается явно, чтобы сервис нельзя было случайно зарегистрировать под его конкретным классом вместо интерфейса.
