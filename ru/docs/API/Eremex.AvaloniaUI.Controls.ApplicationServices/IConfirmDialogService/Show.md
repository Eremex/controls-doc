# Метод IConfirmDialogService.Show (1 из 2)

Показывает диалог, если только пользователь уже не попросил его не показывать.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls.ApplicationServices`](../index.md)  
**Сборка:** `Eremex.Common.Contracts.dll`  
**NuGet-пакет:** [Eremex.Common.Contracts](https://www.nuget.org/packages/Eremex.Common.Contracts)

## Объявление

```csharp
public DialogResult Show(string key, IEnumerable<string> messages, string title, 
    string? header = null, MessageBoxIcon icon = MessageBoxIcon.None, 
    MessageBoxButtons buttons = MessageBoxButtons.OkCancel)
```

## Параметры

| имя | тип | описание |
| --- | --- | --- |
| key | `string` | Идентифицирует диалог. Диалоги с одинаковым ключом подавляются вместе, поэтому используйте для каждого сообщения отдельный ключ. |
| messages | `IEnumerable<string>` | Строки сообщения, отображаемые в теле диалога. |
| title | `string` | Заголовок окна. |
| header | `string?` | Выделенная строка над сообщениями или `null`. |
| icon | [`MessageBoxIcon`](../../Eremex.AvaloniaUI.Controls/MessageBoxIcon.md) | Значок, отображаемый рядом с сообщениями. |
| buttons | [`MessageBoxButtons`](../../Eremex.AvaloniaUI.Controls/MessageBoxButtons.md) | Набор кнопок, предлагаемых в нижней части диалога. |

## Возвращаемое значение

| тип | описание |
| --- | --- |
| [`DialogResult`](../DialogResult.md) | Результат нажатой кнопки или запомненный результат, если диалог подавлен. |

## Примечания

Выбор «Больше не показывать» сохраняется только тогда, когда пользователь отвечает кнопкой, отличной от Cancel, поэтому отмена диалога никогда не отключает его.

# Метод IConfirmDialogService.Show&lt;TViewModel&gt; (2 из 2)

Показывает диалог с представлением модели представления в качестве содержимого, если только пользователь уже не попросил его не показывать.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls.ApplicationServices`](../index.md)  
**Сборка:** `Eremex.Common.Contracts.dll`  
**NuGet-пакет:** [Eremex.Common.Contracts](https://www.nuget.org/packages/Eremex.Common.Contracts)

## Объявление

```csharp
public DialogResult Show<TViewModel>(string key, TViewModel content, string title, 
    MessageBoxButtons buttons = MessageBoxButtons.OkCancel)
    where TViewModel : class
```

## Параметры типа

| имя | описание |
| --- | --- |
| TViewModel | Тип модели представления содержимого. Она объявляет своё представление с помощью `ViewLocatorAttribute`. |

## Параметры

| имя | тип | описание |
| --- | --- | --- |
| key | `string` | Идентифицирует диалог. Диалоги с одинаковым ключом подавляются вместе, поэтому используйте для каждого сообщения отдельный ключ. |
| content | `TViewModel` | Модель представления, отображаемая в теле диалога. Её представление становится содержимым диалога и получает эту модель представления в качестве контекста данных. |
| title | `string` | Заголовок окна. |
| buttons | [`MessageBoxButtons`](../../Eremex.AvaloniaUI.Controls/MessageBoxButtons.md) | Набор кнопок, предлагаемых в нижней части диалога. |

## Возвращаемое значение

| тип | описание |
| --- | --- |
| [`DialogResult`](../DialogResult.md) | Результат нажатой кнопки или запомненный результат, если диалог подавлен. |

## Исключения

| исключение | условие |
