# Класс WindowAwareViewModel

Базовый класс для ViewModel, отображаемых в собственном окне сервисом IWindowService или IDialogService. Отслеживает окно, к которому привязана ViewModel, закрывает его по запросу и создаёт View, объявленное атрибутом ViewLocatorAttribute.
