# Класс WindowService

Реализация IWindowService по умолчанию. Размещает ViewModel в [`DialogWindow`](./DialogWindow.md), показываемом немодально, и автоматически отвязывает ViewModel после закрытия окна — в том числе когда пользователь закрывает его кнопкой в заголовке.
