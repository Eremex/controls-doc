# Класс DialogWindow

Окно, в котором размещается ViewModel, отображаемая через IDialogService или IWindowService. Отображает Content в основной части и кнопки из ButtonsSource в нижней части, подстраивая свой размер под содержимое. Его создают сервисы; как правило, нет причин создавать его напрямую.

## Примечания

У тела две раскладки. Простое содержимое, а также любое содержимое, если у окна есть класс Message, раскладывается как сообщение: с отступами, с переносом текста, с ограничением ширины и с прокруткой, если оно слишком высокое. Представление (любое содержимое типа Control) в остальных случаях заполняет тело как есть: отступом служит Padding окна, без прокрутки, переноса и ограничения ширины, как того ожидает полноценное представление диалога со своей раскладкой.
