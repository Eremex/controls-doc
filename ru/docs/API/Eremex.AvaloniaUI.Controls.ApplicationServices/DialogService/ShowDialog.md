# Метод DialogService.ShowDialog&lt;T&gt; (2 из 2)

Показывает модальный диалог поверх указанного окна. Если владелец не задан, используется активное окно приложения.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls.ApplicationServices`](../index.md)  
**Сборка:** `Eremex.Avalonia.Controls.ApplicationServices.dll`  
**NuGet-пакет:** [Eremex.Avalonia.Controls.ApplicationServices](https://www.nuget.org/packages/Eremex.Avalonia.Controls.ApplicationServices)

## Объявление

```csharp
public DialogResult ShowDialog<T>(T viewModel, string? caption, Window? owner)
    where T : IDialogAwareViewModel
```

## Параметры типа

| имя | описание |
| --- | --- |
| T | Тип ViewModel, управляющей диалогом. |

## Параметры

| имя | тип | описание |
| --- | --- | --- |
| viewModel | `T` | Отображаемая ViewModel. Она задаёт содержимое и кнопки диалога и остаётся привязанной к окну до закрытия диалога. |
| caption | `string?` | Заголовок окна. Если равен `null`, заголовок берётся из Title. |
| owner | `Window?` | Окно, поверх которого отображается диалог. Если равно `null`, используется активное окно приложения. |

## Возвращаемое значение

| тип | описание |
| --- | --- |
| `DialogResult` | Кнопка, которой был закрыт диалог, или None, если пользователь закрыл его кнопкой в заголовке окна. |

## Исключения

| исключение | условие |
| --- | --- |
| ArgumentNullException | *viewModel* равно `null`. |
