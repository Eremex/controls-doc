# Класс SplashScreenViewModel

Модель представления универсальной заставки. Содержит только данные для отображения и не привязана к бренду приложения; приложение задаёт оформление, наследуясь от неё и присваивая свойства (фоновое изображение, версию, авторские права) в конструкторе.
