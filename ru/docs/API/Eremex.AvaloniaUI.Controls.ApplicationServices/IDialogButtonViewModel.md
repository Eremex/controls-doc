# Интерфейс IDialogButtonViewModel

Описывает одну кнопку в нижней части диалога: как она выглядит, где расположена и что делает при нажатии. Диалог предоставляет свои кнопки через [`ButtonsSource`](./IDialogAwareViewModel/ButtonsSource.md).
