## Примечания

Дополняет [`IMessageBoxService`](./IMessageBoxService.md), который поддерживает только фиксированные наборы кнопок (Ok/OkCancel/YesNo/AbortRetryIgnore/RetryCancel) и возвращает [`DialogResult`](./DialogResult.md). Этот сервис предназначен для случаев, когда подписи кнопок задаются кодом приложения, например "Show log" / "Close". Окно-владелец определяется базовым сервисом [`IDialogService`](./IDialogService.md) через `IWindowsManager`, поэтому здесь его указывать не нужно.
