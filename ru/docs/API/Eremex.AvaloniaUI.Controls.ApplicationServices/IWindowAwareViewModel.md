# Интерфейс IWindowAwareViewModel

Реализуется ViewModel, отображаемыми в собственном окне. Сервисы окон вызывают [`Attach`](./IWindowAwareViewModel/Attach.md) перед показом окна и [`Detach`](./IWindowAwareViewModel/Detach.md) после его закрытия, что позволяет ViewModel наблюдать за своим окном, не завися ни от какого типа окна.
