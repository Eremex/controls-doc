# Интерфейс IWindow

Окно приложения с точки зрения этих сервисов. ViewModel получает его от [`IWindowsManager`](./IWindowsManager.md) и передаёт обратно в качестве владельца запрашиваемого диалога, никогда не называя тип окна UI-фреймворка.

## Примечания

Эта сборка не ссылается на UI-фреймворк, поэтому окно не может фигурировать здесь в виде своего типа из фреймворка. Слой UI представляет свои окна через этот интерфейс и преобразует их обратно, когда нужно показать диалог, — точно так же, как параметры файлового диалога преобразуются в типы, ожидаемые средством выбора платформы.
