# Конструктор DialogButtonViewModel (2 из 2)

Инициализирует полностью настроенную кнопку. Фабричные методы `Create*` вызывают этот конструктор с параметрами каждой стандартной кнопки.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls.ApplicationServices`](../index.md)  
**Сборка:** `Eremex.Avalonia.Controls.ApplicationServices.dll`  
**NuGet-пакет:** [Eremex.Avalonia.Controls.ApplicationServices](https://www.nuget.org/packages/Eremex.Avalonia.Controls.ApplicationServices)

## Объявление

```csharp
public DialogButtonViewModel(string caption, ICommand command, object? commandParameter, 
    string? classes, bool isDefault = false, bool isCancel = false, 
    DockType dockType = DockType.Right, int? index = null, 
    DialogButtonType buttonType = DialogButtonType.Button)
```

## Параметры

| имя | тип | описание |
| --- | --- | --- |
| caption | `string` | Текст, отображаемый на кнопке. |
| command | `ICommand` | Команда, вызываемая при нажатии кнопки. |
| commandParameter | `object?` | Значение, передаваемое в *command*. |
| classes | `string?` | Классы стилей, разделённые пробелами, применяемые к кнопке. |
| isDefault | `bool` | `true`, чтобы сделать эту кнопку кнопкой по умолчанию, активируемой клавишей Enter. |
| isCancel | `bool` | `true`, чтобы сделать эту кнопку кнопкой отмены, активируемой клавишей Escape. |
| dockType | `DockType` | Сторона нижней части диалога, к которой прикреплена кнопка. |
| index | `int?` | Позиция среди кнопок, прикреплённых к той же стороне, в порядке возрастания. `null` сохраняет порядок объявления. |
| buttonType | `DialogButtonType` | Отображать ли обычную кнопку или флажок. |
