# Метод DialogButtonViewModel.CreateCustom

Создаёт кнопку с собственными подписью, расположением и оформлением для действий, специфичных для одного диалога.

```csharp
public static IDialogButtonViewModel CreateCustom(ICommand command, string content, 
    object? commandParameter = null, DockType dockType = DockType.Right, int? index = null, 
    string? classes = null)
```

## Параметры

| имя | тип | описание |
| --- | --- | --- |
| command | `ICommand` | Команда, вызываемая при нажатии кнопки. |
| content | `string` | Подпись кнопки. Используется как есть, без локализации. |
| commandParameter | `object?` | Значение, передаваемое в *command*. |
| dockType | `DockType` | Сторона нижней части диалога, к которой прикреплена кнопка. |
| index | `int?` | Позиция среди кнопок, прикреплённых к той же стороне, в порядке возрастания. `null` сохраняет порядок объявления. |
| classes | `string?` | Дополнительные классы стилей кнопки, разделённые пробелами, которые добавляются к стандартному оформлению кнопок диалога. |
