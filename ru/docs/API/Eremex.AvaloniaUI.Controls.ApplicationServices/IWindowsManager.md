# Интерфейс IWindowsManager

Отслеживает окна приложения, чтобы другие сервисы знали, к какому окну относится новый диалог. Реализации следят за активацией и закрытием окон, поэтому один экземпляр должен существовать на протяжении всей работы приложения.
