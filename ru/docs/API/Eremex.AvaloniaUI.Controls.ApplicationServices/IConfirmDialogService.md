# Интерфейс IConfirmDialogService

Показывает диалог подтверждения или уведомления с флажком «Больше не показывать» и учитывает выбор пользователя: как только флажок установлен и на диалог дан ответ, диалог с тем же ключом больше не показывается, а вместо него возвращается запомненный ответ.

| --- | --- |
| [Reset](IConfirmDialogService/Reset.md)(…) | Снова показывает подавленный диалог. |

## Примечания

Выбор хранится в [`IApplicationSettingsService`](./IApplicationSettingsService.md). Для диалогов, которые должны появляться всегда, используйте [`IMessageBoxService`](./IMessageBoxService.md).
