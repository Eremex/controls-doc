# Класс WindowInterop

Выполняет преобразование между не зависящим от фреймворка контрактом IWindow и окном Avalonia.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls.ApplicationServices`](./index.md)

| static [AsWindow](WindowInterop/AsWindow.md)(…) | Представляет окно Avalonia через не зависящий от фреймворка контракт, принимаемый сервисами. |

## Примечания

Сборка контрактов не может ссылаться на Avalonia, поэтому окно попадает в сервис в виде IWindow. Это единственное место, где окно Avalonia представляется через этот контракт и преобразуется из него обратно.
