# Интерфейс IDialogResultWindow

Окно диалога, запоминающее результат, с которым оно было закрыто. Модель представления закрывает своё окно через [`CloseWithResult`](./IDialogResultWindow/CloseWithResult.md), чтобы результат был доступен из [`Result`](./IDialogResultWindow/Result.md), а не только при модальном показе; это важно, когда диалог показывается немодально (например, при запуске приложения, пока нет окна-владельца).
