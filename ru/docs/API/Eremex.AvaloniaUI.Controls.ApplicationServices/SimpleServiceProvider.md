# Класс SimpleServiceProvider

Минимальная реализация IServiceProvider без зависимости от какого-либо DI-контейнера. Предназначена для приложений и тестов, которым не нужен полноценный контейнер. Приложения с контейнером регистрируют сервисы по-своему, см. [`RegisterApplicationServices`](./ApplicationServicesContext/RegisterApplicationServices.md).

## Примечания

Все сервисы создаются отложенно и живут как синглтоны. Созданные экземпляры, реализующие IDisposable, освобождаются методом [`Dispose`](./SimpleServiceProvider/Dispose.md).
