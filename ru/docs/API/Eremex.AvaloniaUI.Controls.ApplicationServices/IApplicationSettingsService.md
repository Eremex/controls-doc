# Интерфейс IApplicationSettingsService

Хранит настройки приложения как значения, адресуемые по ключу, например выбор «больше не показывать» в диалогах подтверждения или последнюю использованную папку.

## Примечания

Реализация по умолчанию хранит значения только в памяти. Приложение, которому нужно, чтобы значения сохранялись после перезапуска, регистрирует собственную реализацию на основе своего хранилища настроек. Ключи чувствительны к регистру; используйте префикс, определяющий функциональность, например `"ConfirmDialog.Suppress.MyKey"`.
