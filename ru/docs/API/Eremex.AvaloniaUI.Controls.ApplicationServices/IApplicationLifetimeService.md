# Интерфейс IApplicationLifetimeService

Отслеживает время жизни приложения: сообщает, что приложение останавливается, и завершает его по запросу, чтобы код модели представления мог наблюдать за завершением и инициировать его, не обращаясь напрямую ко времени жизни приложения UI-фреймворка.
