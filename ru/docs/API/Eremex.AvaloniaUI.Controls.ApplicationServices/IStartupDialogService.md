# Интерфейс IStartupDialogService

[`IDialogService`](./IDialogService.md) для диалогов, показываемых при запуске приложения, до появления главного окна. Если нет окна-владельца, сервис показывает диалог немодально и запускает локальный цикл сообщений, пока диалог не закроется, так что результат всё равно можно вернуть.
