# Класс AvaloniaStorageDialogBase

Базовый класс для диалогов выбора в хранилище, используемых сервисами файловых диалогов. Содержит общие для всех диалогов выбора параметры — заголовок и начальную папку — и преобразует их в параметры поставщика хранилища Avalonia.
