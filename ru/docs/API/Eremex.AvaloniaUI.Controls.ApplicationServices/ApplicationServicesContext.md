# Класс ApplicationServicesContext

Глобальный доступ к сервисам приложения и описание их состава.

Класс не привязан ни к какому конкретному DI-контейнеру: единственный тип интеграции — IServiceProvider из BCL. Состав сервисов описывается методом [`RegisterApplicationServices`](./ApplicationServicesContext/RegisterApplicationServices.md), а время жизни и регистрацию выбирает хост.

[`Current`](./ApplicationServicesContext/Current.md) предназначен только для мест, куда не может дотянуться внедрение через конструктор: расширений разметки, присоединённых свойств, конвертеров, code-behind без контейнера. Сами сервисы библиотеки получают зависимости через конструкторы и никогда не обращаются к глобальному контексту.
