# Поле DialogWindowClasses.Message

Раскладывает представление как сообщение: содержимое получает отступы, текст переносится, ширина ограничена, а при слишком большой высоте появляется прокрутка. Простое (не control) содержимое всегда получает такую раскладку; представление в остальных случаях заполняет окно как есть, как того ожидает полноценное представление диалога.
