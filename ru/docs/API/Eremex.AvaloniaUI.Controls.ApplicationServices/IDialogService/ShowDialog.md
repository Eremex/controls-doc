# Метод IDialogService.ShowDialog&lt;T&gt;

Показывает ViewModel в модальном диалоге и возвращает управление, когда пользователь его закрывает.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls.ApplicationServices`](../index.md)  
**Сборка:** `Eremex.Common.Contracts.dll`  
**NuGet-пакет:** [Eremex.Common.Contracts](https://www.nuget.org/packages/Eremex.Common.Contracts)

## Объявление

```csharp
public DialogResult ShowDialog<T>(T viewModel, string? caption = null)
    where T : IDialogAwareViewModel
```

## Параметры типа

| имя | описание |
| --- | --- |
| T | Тип ViewModel, управляющей диалогом. |

## Параметры

| имя | тип | описание |
| --- | --- | --- |
| viewModel | `T` | Отображаемая ViewModel. Она задаёт содержимое и кнопки диалога и привязана к окну на всё время, пока открыт диалог. |
| caption | `string?` | Заголовок окна. Если равен `null`, заголовок берётся из [`Title`](../IWindowAwareViewModel/Title.md). |

## Возвращаемое значение

| тип | описание |
| --- | --- |
| [`DialogResult`](../DialogResult.md) | Кнопка, которой был закрыт диалог, или None, если пользователь закрыл его кнопкой в заголовке окна. |
