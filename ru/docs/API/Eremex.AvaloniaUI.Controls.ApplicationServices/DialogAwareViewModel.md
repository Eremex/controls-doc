# Класс DialogAwareViewModel

Базовый класс для ViewModel, отображаемых сервисом IDialogService в виде модальных диалогов. Поверх [`WindowAwareViewModel`](./WindowAwareViewModel.md) создаёт кнопки диалога при открытии окна.
