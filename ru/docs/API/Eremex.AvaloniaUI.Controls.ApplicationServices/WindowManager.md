# Класс WindowManager

Реализация IWindowsManager по умолчанию. Отслеживает активацию окон, чтобы знать, какое окно активно, и отключает окна за модальным диалогом, чтобы взаимодействовать можно было только с диалогом, — используя механизм платформы в Windows и X11, если он доступен.
