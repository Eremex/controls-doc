# Интерфейс IDialogService

Показывает диалоги приложения из кода ViewModel, чтобы ViewModel могла задать пользователю вопрос, не ссылаясь ни на какой тип окна. View, в котором размещается ViewModel, находится с помощью [`ViewLocatorAttribute`](./ViewLocatorAttribute.md), а окно-владельца выбирает реализация.
