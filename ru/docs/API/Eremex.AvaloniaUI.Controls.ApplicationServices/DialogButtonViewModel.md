# Класс DialogButtonViewModel

Стандартная реализация IDialogButtonViewModel. Для распространённых кнопок используйте фабричные методы `Create*` — они задают правильные подпись, классы стилей и поведение кнопки по умолчанию/отмены — и возвращайте результаты из CreateButtons.
