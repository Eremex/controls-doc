# Класс JsonFileApplicationSettingsService

Реализация IApplicationSettingsService по умолчанию: хранит значения в JSON-файле в папке данных приложения текущего пользователя, поэтому они сохраняются после перезапуска приложения.

## Примечания

Файл `settings.json` находится в папке, названной по входной сборке, внутри `%AppData%` в Windows, `~/Library/Application Support` в macOS и `$XDG_CONFIG_HOME` (по умолчанию `~/.config`) в Linux. Файл читается при первом использовании и перезаписывается после каждого изменения. Отсутствующий, нечитаемый или повреждённый файл считается пустым, а сбой записи никогда не вызывает исключение: значения остаются доступными в памяти до конца сеанса.
