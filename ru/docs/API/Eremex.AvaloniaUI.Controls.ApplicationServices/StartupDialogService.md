# Класс StartupDialogService

Реализация IStartupDialogService по умолчанию. Размещает модель представления в [`DialogWindow`](./DialogWindow.md), как [`DialogService`](./DialogService.md), но допускает отсутствие окна-владельца: при запуске приложения, пока нет ни одного окна, она показывает диалог немодально и запускает локальный цикл сообщений, пока диалог не закроется, так что результат всё равно возвращается.
