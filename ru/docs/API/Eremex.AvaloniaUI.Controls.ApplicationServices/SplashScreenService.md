# Класс SplashScreenService

Реализация ISplashScreenService по умолчанию. Показывает универсальное окно [`SplashScreen`](./SplashScreen.md), управляемое [`SplashScreenViewModel`](./SplashScreenViewModel.md). Приложение добавляет собственное оформление, наследуясь от этого сервиса и переопределяя CreateViewModel, чтобы вернуть настроенную (возможно, производную) модель представления.
