# Метод IOpenFileDialogService.ShowAsync

Показывает диалог открытия файла, не блокируя вызывающий поток.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls.ApplicationServices`](../index.md)  
**Сборка:** `Eremex.Common.Contracts.dll`  
**NuGet-пакет:** [Eremex.Common.Contracts](https://www.nuget.org/packages/Eremex.Common.Contracts)

## Объявление

```csharp
public Task<string[]> ShowAsync(IWindow? owner = null, OpenFileDialogOptions? options = null)
```

## Параметры

| имя | тип | описание |
| --- | --- | --- |
| owner | [`IWindow?`](../IWindow.md) | Окно, поверх которого отображается диалог. Если равно `null`, используется активное окно приложения. |
| options | [`OpenFileDialogOptions?`](../OpenFileDialogOptions.md) | Конфигурация диалога — заголовок, фильтры, начальная папка, множественный выбор. Если равна `null`, применяются значения платформы по умолчанию. |

## Возвращаемое значение

| тип | описание |
| --- | --- |
| `Task<string[]>` | Задача, которая завершается при закрытии диалога и содержит пути выбранных файлов или пустой массив, если пользователь отменил диалог или окно-владельца не удалось определить. |
