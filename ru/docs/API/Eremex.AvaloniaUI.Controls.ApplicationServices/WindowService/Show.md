# Метод WindowService.Show&lt;T&gt; (2 из 2)

Показывает немодальное окно. Если владелец не задан, используется активное окно приложения.

**Пространство имён:** [`Eremex.AvaloniaUI.Controls.ApplicationServices`](../index.md)  
**Сборка:** `Eremex.Avalonia.Controls.ApplicationServices.dll`  
**NuGet-пакет:** [Eremex.Avalonia.Controls.ApplicationServices](https://www.nuget.org/packages/Eremex.Avalonia.Controls.ApplicationServices)

## Объявление

```csharp
public void Show<T>(T viewModel, string? caption, Window? owner)
    where T : IWindowAwareViewModel
```

## Параметры типа

| имя | описание |
| --- | --- |
| T | Тип ViewModel, управляющей окном. |

## Параметры

| имя | тип | описание |
| --- | --- | --- |
| viewModel | `T` | Отображаемая ViewModel. Она остаётся привязанной к окну до его закрытия. |
| caption | `string?` | Заголовок окна. Если равен `null`, заголовок берётся из Title. |
| owner | `Window?` | Окно-владелец нового окна. Если равно `null`, используется активное окно приложения; если его нет, окно отображается без владельца. |

## Исключения

| исключение | условие |
| --- | --- |
| ArgumentNullException | *viewModel* равно `null`. |
