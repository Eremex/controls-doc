# Класс SplashScreen

Универсальное окно-заставка без привязки к бренду, показываемое [`SplashScreenService`](./SplashScreenService.md). Оно привязывается к [`SplashScreenViewModel`](./SplashScreenViewModel.md) и отображает фоновое изображение и строки текста; приложение настраивает его, предоставляя производную модель представления.
