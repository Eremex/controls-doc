# Свойство OpenFileDialogOptions.Filter

Фильтры типов файлов, записанные как чередующиеся отображаемое имя и шаблоны, разделённые символом `|`, где несколько шаблонов для одного типа разделяются символом `;`, а каждый шаблон — это glob, например `*.png`, — например, `"Images|*.png;*.jpg|All files|*.*"`. Если свойство не задано, отображаются все файлы.
