# Перечисление DialogResult

Обозначает кнопку, которой был закрыт модальный диалог или окно сообщения.

## Значения

| имя | значение | описание |
| --- | --- | --- |
| None | `0` | Диалог был закрыт без нажатия какой-либо из его кнопок, например кнопкой в заголовке окна. Это значение также возвращается, пока диалог ещё открыт. |
| Ok | `1` | Пользователь подтвердил диалог, нажав кнопку OK. |
| Cancel | `2` | Пользователь закрыл диалог, нажав кнопку Cancel. |
| Abort | `3` | Пользователь нажал кнопку Abort, чтобы полностью прервать операцию. |
| Retry | `4` | Пользователь нажал кнопку Retry, чтобы повторить неудавшуюся операцию. |
| Ignore | `5` | Пользователь нажал кнопку Ignore, чтобы пропустить проблему и продолжить. |
| Yes | `6` | Пользователь ответил на вопрос кнопкой Yes. |
| No | `7` | Пользователь ответил на вопрос кнопкой No. |
