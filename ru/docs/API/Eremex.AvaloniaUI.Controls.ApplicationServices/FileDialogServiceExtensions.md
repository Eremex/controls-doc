# Класс FileDialogServiceExtensions

Формы сервисов файловых диалогов, принимающие только параметры либо владельца в виде Avalonia TopLevel, для кода, который не работает с контрактом IWindow. Окно верхнего уровня, не являющееся Window, не даёт владельца, поэтому используется активное окно приложения.
