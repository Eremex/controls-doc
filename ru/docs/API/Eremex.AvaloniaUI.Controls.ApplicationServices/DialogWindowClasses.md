# Класс DialogWindowClasses

Имена классов стилей, распознаваемых окном диалога. Передавайте их в [`ViewLocatorAttribute`](./ViewLocatorAttribute.md), чтобы выбрать внешний вид окна, в котором размещается ViewModel, вместо повторения строковых литералов в каждом месте вызова.

| const [MaxSize](DialogWindowClasses/MaxSize.md) | Задаёт диалогу наибольшую из предопределённых ширин. |
