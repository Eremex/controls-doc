# Интерфейс IWindowService

Показывает немодальные окна приложения из кода ViewModel, чтобы ViewModel могла открыть окно, не ссылаясь ни на какой тип окна. Аналог для модальных диалогов — [`IDialogService`](./IDialogService.md).
