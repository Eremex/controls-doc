# Свойство CrosshairOptions.MaxPickDistance

Возвращает или задаёт наибольшее расстояние от указателя, на котором точка данных ещё выбирается перекрестием, в аппаратно-независимых единицах. Увеличьте это значение для разреженных серий, точки которых не находятся прямо под указателем.

**Пространство имён:** [`Eremex.AvaloniaUI.Charts`](../index.md)  
**Сборка:** `Eremex.Avalonia.Charts.dll`  
**NuGet-пакет:** [Eremex.Avalonia.Controls](https://www.nuget.org/packages/Eremex.Avalonia.Controls)

## Объявление

```csharp
public int MaxPickDistance { get; set; }
```

## Примечания

Значение ноль или меньше снимает ограничение, поэтому выбирается ближайшая точка данных независимо от её удалённости от указателя. Это значение по умолчанию.
