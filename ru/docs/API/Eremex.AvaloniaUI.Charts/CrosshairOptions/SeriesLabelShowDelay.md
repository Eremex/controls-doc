# Свойство CrosshairOptions.SeriesLabelShowDelay

Возвращает или задаёт, сколько времени в миллисекундах перекрестие должно оставаться на одних и тех же данных, прежде чем появятся метки серий.

**Пространство имён:** [`Eremex.AvaloniaUI.Charts`](../index.md)  
**Сборка:** `Eremex.Avalonia.Charts.dll`  
**NuGet-пакет:** [Eremex.Avalonia.Controls](https://www.nuget.org/packages/Eremex.Avalonia.Controls)

## Объявление

```csharp
public int SeriesLabelShowDelay { get; set; }
```

## Примечания

Отсчёт начинается заново каждый раз, когда перекрестие переходит к другой точке данных, поэтому увеличьте это значение, чтобы метки не появлялись, пока указатель перемещается по области графика. Значение ноль или меньше убирает задержку, и метки серий появляются сразу; это значение по умолчанию. Задержка применяется только к меткам серий; метки аргумента и значения на осях всегда следуют за указателем.
