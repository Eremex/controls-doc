# Перечисление AxisTitlePosition

Перечисляет значения, задающие расположение заголовка оси относительно меток оси.

## Значения

| имя | значение | описание |
| --- | --- | --- |
| Near | `0` | Заголовок располагается снизу или слева от оси. |
| Center | `1` | Заголовок располагается по центру оси. |
| Far | `2` | Заголовок располагается сверху или справа от оси. |
| WithLabels | `3` | Заголовок располагается там, где была бы отображена крайняя метка оси. |
