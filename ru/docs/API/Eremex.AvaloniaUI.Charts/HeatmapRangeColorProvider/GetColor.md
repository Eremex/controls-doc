# Метод HeatmapRangeColorProvider.GetColor

Возвращает цвет, интерполированный между двумя опорными точками диапазона, окружающими указанное значение.

**Пространство имён:** [`Eremex.AvaloniaUI.Charts`](../index.md)  
**Сборка:** `Eremex.Avalonia.Charts.dll`  
**NuGet-пакет:** [Eremex.Avalonia.Controls](https://www.nuget.org/packages/Eremex.Avalonia.Controls)

```csharp
public Color GetColor(double value, IMinMaxValues range)
```

| тип | описание |
| --- | --- |
| `Color` | Цвет ячейки. Значения ниже первой опорной точки диапазона получают цвет этой точки, а значения, равные последней опорной точке или превышающие её, получают цвет этой точки. |
