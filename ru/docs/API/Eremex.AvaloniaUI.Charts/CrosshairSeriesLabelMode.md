# Перечисление CrosshairSeriesLabelMode

Перечисляет значения, задающие, значения скольких серий показывает перекрестие.

## Значения

| имя | значение | описание |
| --- | --- | --- |
| None | `0` | Перекрестие не показывает значений серий. |
| ForNearestSeries | `1` | Перекрестие показывает значения одной серии, ближайшей к указателю. |
| ForEachSeries | `2` | Перекрестие показывает значения каждой серии в отдельной метке. |
| OneForAllSeries | `3` | Перекрестие показывает значения всех серий в одной общей метке. |
| Smart | `4` | Перекрестие работает как в режиме ForEachSeries, но перекрывающиеся метки объединяются в одну. |
