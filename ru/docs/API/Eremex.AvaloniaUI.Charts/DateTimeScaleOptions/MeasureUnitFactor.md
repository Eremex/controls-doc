# Свойство DateTimeScaleOptions.MeasureUnitFactor

Возвращает или задаёт количество интервалов MeasureUnit, составляющих один шаг на оси.

**Пространство имён:** [`Eremex.AvaloniaUI.Charts`](../index.md)

## Примечания

Значение никогда не бывает меньше единицы. Например, значение три при MeasureUnit, равном Month, группирует данные по кварталам.
