# Свойство DateTimeScaleOptions.MeasureUnit

Возвращает или задаёт единицу даты и времени, до которой округляются значения данных. Значения, попадающие в одну единицу, отображаются в одной позиции, поэтому серия показывает их как одно значение. Например, 2026-01-01 10:20 и 2026-01-01 13:40 занимают одну позицию, если это свойство равно Day, и разные позиции, если оно равно Hour.

## Примечания

Это свойство задаёт детализацию самих данных, а не линий сетки и меток; для них используйте [`GridSpacingUnit`](./GridSpacingUnit.md). Если это свойство равно null, значения отображаются в точной позиции. Оно также задаёт детализацию, с которой привязывается перекрестие, и не позволяет отображать линии сетки мельче этой единицы.
