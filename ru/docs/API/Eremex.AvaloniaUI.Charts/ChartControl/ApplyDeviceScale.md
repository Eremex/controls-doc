# Свойство ChartControl.ApplyDeviceScale

Возвращает или задаёт, делятся ли размеры элементов диаграммы на коэффициент плотности пикселей устройства. Оставьте это свойство отключённым, если только диаграмма не выглядит слишком крупной на дисплее высокого разрешения.
