# Свойство PolarRangeAreaSeriesView.Marker2ImageCss

Возвращает или задаёт CSS, применяемый к изображению маркера второй границы, если это изображение SVG. Текст обрабатывается как строка формата, в которой {0} заменяется цветом маркера в формате #RRGGBB.
