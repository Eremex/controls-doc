# Метод CartesianChart.Scroll

Сдвигает видимый диапазон осей вдоль их осей значений.

**Пространство имён:** [`Eremex.AvaloniaUI.Charts`](../index.md)  
**Сборка:** `Eremex.Avalonia.Charts.dll`  
**NuGet-пакет:** [Eremex.Avalonia.Controls](https://www.nuget.org/packages/Eremex.Avalonia.Controls)

## Объявление

```csharp
public void Scroll(double deltaX, double deltaY, IEnumerable<Axis>? axes = null)
```

## Параметры

| имя | тип | описание |
| --- | --- | --- |
| deltaX | `double` | Горизонтальный сдвиг, выраженный долей видимого диапазона. Положительные значения сдвигают диапазон в сторону больших значений X. |
| deltaY | `double` | Вертикальный сдвиг, выраженный долей видимого диапазона. Положительные значения сдвигают диапазон в сторону больших значений Y. |
| axes | `IEnumerable<Axis>?` | Оси для прокрутки. Передайте `null`, чтобы прокрутить все оси диаграммы. |

## Примечания

Каждый сдвиг применяется только к осям соответствующего направления: горизонтальный сдвиг влияет на горизонтальные оси, а вертикальный — на вертикальные.
