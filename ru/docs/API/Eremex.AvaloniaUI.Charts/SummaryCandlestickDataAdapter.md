# Класс SummaryCandlestickDataAdapter

Сводит аргументы даты и времени в точки данных свечей. Все исходные значения, попадающие в одну единицу измерения, образуют одну свечу, в которой значения открытия и закрытия — это первое и последнее значения группы, а минимальное и максимальное значения — минимум и максимум группы.
