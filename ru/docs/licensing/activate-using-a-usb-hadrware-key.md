# Активация с помощью аппаратного USB-ключа

1. Установите службу [_Guardant Control Center_ (GCC)](activate-and-manage-local-licenses.md#license-management-utilities) на целевую машину (машину разработчика для [локальной лицензии](activate-and-manage-local-licenses.md) или сервер для [сетевой лицензии](activate-and-manage-network-licenses.md)).

2. Вставьте аппаратный ключ Guardant в свободный USB-порт машины.


## Установка USB-ключа в Windows

Новые модели аппаратных ключей Guardant могут работать в операционных системах Windows в режиме HID без установки дополнительных драйверов.

При подключении аппаратного ключа в режиме HID к USB-порту компьютера система распознает его как стандартное HID-совместимое устройство. При этом должна быть запущена служба _Guardant Dongle License Service_.


## Установка USB-ключа в Linux

Все новые модели аппаратных ключей Guardant, начиная с Guardant Sign, поддерживают Linux и могут работать в режиме HID. Также поддерживаются защищенные Windows-приложения, работающие под WINE.

Чтобы использовать USB-ключ в GNU/Linux, необходимо добавить правило горячего подключения. В большинстве современных дистрибутивов с ядром 2.6.x обработкой горячего подключения занимается **udev**.

Примечание. Для записи в `/etc/udev/rules.d/` требуются права суперпользователя (root).

### Добавление правила **udev**

Устанавливаемое правило зависит от режима работы USB-ключа:

**Режим драйвера** (а также при использовании файлов устройств из файловой системы USB (usbfs)):

``` bash
# cp etc/grdnt.udev /etc/udev/rules.d/95-grdnt.rules
```

**Режим HID**:

``` bash
# cp etc/grdnt_hid.udev /etc/udev/rules.d/95-grdnt_hid.rules
```

Чтобы правила вступили в силу, переподключите USB-ключ (или перезапустите службу **udev**).

Данные правила указывают **udev** установить права на чтение и запись для файла устройства, представляющего USB-ключ Guardant. Это предоставляет доступ к ключу всем пользователям системы.

## Проверка лицензии

После установки USB-ключа откройте веб-интерфейс GCC по адресу [http://localhost:3189/](http://localhost:3189/). Лицензия USB-ключа должна отображаться в списке лицензий. Пароль по умолчанию для веб-интерфейса: `admin`.
