# Сохранение и восстановление лайаута

TreeList позволяет сохранять размещение своих колонок, а затем восстанавливать его позже. Используйте методы [`TreeListControl.SaveLayout`](../../API/Eremex.AvaloniaUI.Controls.TreeList/TreeListControl/SaveLayout.md) и [`TreeListControl.RestoreLayout`](../../API/Eremex.AvaloniaUI.Controls.TreeList/TreeListControl/RestoreLayout.md) для сериализации и десериализации размещения.
