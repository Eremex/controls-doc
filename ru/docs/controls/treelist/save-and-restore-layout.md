# Сохранение и восстановление лайаута

TreeList позволяет сохранять размещение своих колонок, а затем восстанавливать его позже. Используйте методы `TreeListControl.SaveLayout` и `TreeListControl.RestoreLayout` для сериализации и десериализации размещения.
