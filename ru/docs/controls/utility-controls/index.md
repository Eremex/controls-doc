# Вспомогательные контролы

Несколько вспомогательных контролов, поставляемых с библиотекой Eremex Controls, помогают создавать функциональный и привлекательный интерфейс.

![utility-controls](../../images/utility-controls.png)

- [MxTabControl](tabcontrol.md) — контрол, позволяющий объединять панели в интерфейс с вкладками.
    - Неограниченное число вкладок.
    - Заполнение вкладок и их содержимого из источника объектов.
    - Изменение порядка вкладок с помощью перетаскивания.
    - Режимы размещения вкладок: растягивание, прокрутка и в несколько строк.
    - Кнопки «Закрыть вкладку».
    - Кнопка «Новая вкладка».
    - Пользовательские контролы в области заголовков вкладок.

- [MxSplitButton](splitbutton.md) — объединяет две кнопки в одном контроле. Основная кнопка выполняет главное действие контрола, а вторичная кнопка вызывает связанный с `MxSplitButton` выпадающий контрол/меню.
    - Вы можете задать главное действие с помощью события или команды.
    - Выпадающим элементом MxSplitButton может быть всплывающее меню или пользовательский всплывающий контрол.
    
- [SplitContainerControl](splitcontainercontrol.md) — разделяет две панели разделителем.
    - Пользователь может перетаскивать разделитель, чтобы изменять размер панелей.
    - Вертикальное или горизонтальное расположение панелей.
    - Возможность сворачивать/разворачивать одну из панелей.
    - Опция скрытия разделителя.

- `ColorEditor` — самостоятельный контрол, позволяющий пользователю выбрать цвет. 
    - ColorEditor используется как часть контрола PopupColorEditor, а также может использоваться как самостоятельный контрол.
    - Три цветовые палитры — Default, Standard, Custom.
    - Палитру Default можно инициализировать в коде.
    - Палитра Standard отображает предопределённые стандартные цвета.
    - Палитра Custom позволяет пользователям добавлять и изменять цвета с помощью встроенного Color Picker.
    - Возможность задавать цвета в форматах RGB и HSB.

- [CalendarControl](calendarcontrol.md) — самостоятельный контрол, позволяющий пользователю выбрать дату. 
    - CalendarControl используется как часть контрола DateEditor. Вы также можете использовать его как самостоятельный контрол.
    - Выбор даты в календаре с помощью мыши и клавиатуры.
    - Панель навигации позволяет перемещаться по месяцам и годам.
    - Три представления календаря: представление месяца, представление года и представление диапазона лет.
    - Опция ограничения доступного диапазона дат.

- [GroupBox](groupbox.md) — панель с заголовком.
    - Заголовок контрола позволяет отображать пользовательский текст.
    - Контрол отображает линию под клиентской областью.



- `CircleProgressIndicator` — отображает ход выполнения операции в виде вращающегося круга.
