# Окна и диалоговые окна


Библиотека контролов Eremex включает компоненты Window и MessageBox, которые поддерживают визуальные темы Eremex. Используя контролы Eremex вместе с окнами и диалогами Eremex, вы можете добиться единообразного внешнего вида интерфейса.

## MxWindow

`MxWindow` — это окно, которое использует визуальные темы Eremex для отрисовки заголовка и рамок окна.

![mxwindow](../../images/mxwindow.png)

- `MxWindow` является потомком компонента Window.
- Предоставляет параметры для настройки видимости стандартных кнопок в заголовке
- Предоставляет параметры для задания пользовательских глифов этих кнопок

[Подробнее](mxwindow.md)

## MxMessageBox

`MxMessageBox` позволяет отображать окно сообщения в виде модального окна.

![mxmessagebox](../../images/mxmessagebox.png)

- Диалог может отображать текстовое сообщение, значок и набор стандартных кнопок.
- Полная поддержка визуальных тем Eremex.
- Простой и единообразный API.

[Подробнее](messagebox.md)
