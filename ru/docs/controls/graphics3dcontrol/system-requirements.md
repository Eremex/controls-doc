# Системные требования

`Graphics3DControl` построен на Vulkan SDK 1.1. Vulkan использует отрисовку с аппаратным ускорением GPU, когда это поддерживается оборудованием. Такой подход обеспечивает значительно более высокую производительность по сравнению с программной отрисовкой.

## Требования к GPU

Чтобы использовать отрисовку с аппаратным ускорением GPU, ваша система должна удовлетворять следующим требованиям:

- GPU, совместимый с Vulkan
- Графический драйвер с поддержкой Vulkan 1.1

Чтобы проверить, совместимы ли ваш GPU и его драйвер с Vulkan, смотрите следующую ссылку:

- [Devices - Vulkan Hardware Database](https://vulkan.gpuinfo.org/)


Если вы столкнулись с проблемами отрисовки, вы можете проверить систему на совместимость с Vulkan следующим образом:

1. Загрузите Vulkan SDK 
2. Запустите исполняемый файл `vulkaninfo`, чтобы проверить поддержку Vulkan. 

    Подробнее смотрите в следующей статье: [Checking For Vulkan Support](https://docs.vulkan.org/guide/latest/checking_for_support.html)

## Программная реализация отрисовки

Если отрисовка на GPU недоступна (например, в виртуальной машине), вы можете использовать [программные реализации](https://docs.vulkan.org/guide/latest/checking_for_support.html#_software_implementation) API Vulkan. Программная отрисовка обеспечивает заметно более низкую производительность, поскольку опирается на обработку CPU, а не на ускорение GPU.
