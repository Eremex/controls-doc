Tree List поддерживает несколько колонок данных, тогда как Tree View — это одноколоночный контрол.<br><br>- Привязка к самореферентным (плоским) и иерархическим источникам данных<br>- Несвязанный режим (позволяет вручную задавать данные)<br>- Множественное выделение строк<br>- Выбор строк с помощью встроенных флажков<br>- Сортировка данных<br>- Встроенные редакторы<br>- Поиск и фильтрация данных<br>- Перетаскивание строк<br>- Валидация данных<br>- Встроенные и пользовательские контекстные меню<br>- Бэнды колонок<br>[Подробнее...](treelist/index.md) | 
| **Property Grid** |
| ![thumb-propertygrid](../images/thumb-propertygrid.png) | Эффективное решение для просмотра и редактирования свойств одного или нескольких объектов. <br><br>- Автоматическая генерация строк из публичных свойств привязанного объекта (объектов)<br>- Режим ручного создания строк<br>- Объединение строк в строки-категории<br>- Объединение строк во встроенные вкладки<br>- Панель поиска (для быстрого нахождения строк)<br>- Встроенные редакторы<br>[Подробнее...](propertygrid/index.md) |

| ![thumb-propertygrid](../images/thumb-listview.png) | Расширенный список, отображающий элементы в соответствии с вашим шаблоном. Поддерживает сортировку, группировку, фильтрацию и множественное выделение элементов.<br><br>- Два режима размещения элементов: `Stack` (одна колонка элементов) и `Wrap` (многоколоночное размещение с переносом элементов) <br>- Отображение элементов ListView произвольным образом в соответствии с вашим шаблоном<br>- Сортировка и группировка элементов по неограниченному числу свойств<br>- Фильтрация элементов с помощью события<br>- Режимы одиночного и множественного выделения<br>[Подробнее...](listview/index.md) |
