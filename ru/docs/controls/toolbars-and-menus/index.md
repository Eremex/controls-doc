# Панели инструментов и меню

Библиотека EMX Controls содержит компонент `ToolbarManager`, который позволяет создавать традиционные панели инструментов и меню или [Ribbon UI](../ribbon/index.md) в вашем приложении. `ToolbarManager` предлагает богатые возможности для размещения и управления традиционными панелями инструментов, создания контекстных меню, настройки параметров отображения и поведения панелей инструментов, а также настройки панелей во время работы.

![toolbars](../../images/toolbars.png)

Вы можете использовать несколько типов элементов панелей для создания интерфейса меню: обычные кнопки, кнопки-флажки, редакторы, надписи, подменю и групповые элементы.

Панели инструментов могут настраиваться пользователями. Во время работы они могут выбирать, какие команды отображать. 

Основные возможности библиотеки панелей инструментов и меню включают:

- Пользовательская настройка:
    - Перетаскивание панелей — позволяет пользователю переупорядочивать панели с помощью маркеров перетаскивания.
    - Режим настройки и окно настройки — в окне настройки пользователь может изменять видимость существующих панелей инструментов и создавать пользовательские панели. Пользователь может скрывать, восстанавливать и перемещать элементы панелей с помощью перетаскивания.
    - Быстрая настройка — пользователь может перемещать элементы внутри панелей и между ними с помощью перетаскивания, удерживая клавишу Alt. Активировать режим настройки/окно настройки для быстрой настройки не требуется.

- Множество опций компоновки панелей:
    - Горизонтальная и вертикальная ориентации отдельных панелей.
    - Любое положение внутри окна.
    - Растягивание панелей.
    - Адаптивная компоновка панелей — панели инструментов автоматически скрывают и восстанавливают свои элементы при изменении занимаемого ими пространства.
    - Опция показа/скрытия маркеров перетаскивания панелей.
    - Опция показа/скрытия кнопок настройки панелей.
    
- Поддерживаемые элементы панелей: `ToolbarButtonItem`, `ToolbarCheckItem`, `ToolbarMenuItem`, `ToolbarEditorItem`, `ToolbarTextItem`, `ToolbarItemGroup` и `ToolbarCheckItemGroup`.

- Контекстные меню — вы можете создавать контекстные меню для внешних контролов. Настройки стиля контекстных меню согласованы со всеми компонентами библиотеки панелей инструментов и меню.
