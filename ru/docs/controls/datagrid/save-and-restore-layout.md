# Сохранение и восстановление лайаута

DataGrid позволяет сохранить лайаут колонок сетки, а затем восстановить его позднее. Используйте методы [`DataGridControl.SaveLayout`](../../API/Eremex.AvaloniaUI.Controls.DataGrid/DataGridControl/SaveLayout.md) и [`DataGridControl.RestoreLayout`](../../API/Eremex.AvaloniaUI.Controls.DataGrid/DataGridControl/RestoreLayout.md) для сериализации и десериализации лайаута.
