# Сохранение и восстановление лайаута

DataGrid позволяет сохранить лайаут колонок сетки, а затем восстановить его позднее. Используйте методы `DataGridControl.SaveLayout` и `DataGridControl.RestoreLayout` для сериализации и десериализации лайаута.
