# Clipboard

DataGrid теперь поддерживает сочетание клавиш CTRL+C для копирования выделенных строк в буфер обмена.

В коде вы можете использовать метод `CopyToClipboardAsync`, чтобы скопировать выделенные строки. Этот метод является асинхронным — он немедленно возвращает объект `Task`, не дожидаясь завершения операции копирования. 
Асинхронные методы не блокируют поток пользовательского интерфейса.

- Метод `CopyToClipboardAsync` копирует отображаемый текст ячеек выделенных строк. В режиме одиночного выделения в буфер обмена копируется сфокусированная строка. В режиме множественного выделения копируются все выделенные строки. 
- Если выделена строка группировки, она также копируется в буфер обмена. Строки, вложенные в выделенную строку группировки, не копируются, если они не выделены отдельно.
- Заголовки колонок по умолчанию копируются в буфер обмена. Установите параметр `DataGridControl.ClipboardCopyHeaders` в значение false, чтобы предотвратить копирование заголовков колонок.
- Заголовки колонок и значения ячеек в буфере обмена разделяются символами табуляции (TAB).


## Связанный API

- `DataControlBase.SelectionMode` — позволяет включить множественное выделение строк.
- `DataControlBase.SelectedItems` — определяет коллекцию объектов данных (бизнес-объектов), соответствующих выделенным строкам.
- `DataGridControl.GetCellDisplayText` — возвращает отображаемый текст конкретной ячейки, адресуемой по строке и колонке (или имени поля).
- `DataGridControl.ClipboardCopyHeaders` — определяет, копируются ли заголовки колонок в буфер обмена.
