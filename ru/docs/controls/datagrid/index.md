# DataGrid

`DataGridControl` позволяет отображать данные из источника элементов в виде колонок и строк. Он предоставляет широкие возможности форматирования и редактирования данных. Пользователи могут переставлять колонки, редактировать, сортировать, группировать и выполнять поиск данных.

![data-grid](../../images/data-grid.png)

- [Привязка данных](data-binding/index.md) — вы можете привязать контрол к IList, IBindingList, DataTable или любому источнику данных IEnumerable.
- [Сортировка данных](sorting.md) — позволяет сортировать данные по неограниченному количеству колонок.
- [Группировка данных](grouping.md) — функция группировки данных объединяет строки с одинаковыми значениями колонок в одни и те же группы данных. Вы можете группировать данные контрола по нескольким колонкам.
- [Стили](styles.md) — позволяют настраивать параметры внешнего вида элементов контрола в различных состояниях.
- [Операции редактирования данных](data-editing/index.md) — пользователь может редактировать значения ячеек, если редактирование данных включено. Вы можете встраивать редакторы Eremex и пользовательские редакторы в ячейки для редактирования и определённого способа отображения значений ячеек.
- Валидация данных — механизм валидации помогает проверять пользовательский ввод и значения источника данных, а также отображать ошибки в ячейках.
- [Встроенные и пользовательские контекстные меню](context-menus.md)
- [Несвязанные колонки](data-binding/unbound-columns.md) — вы можете добавлять несвязанные колонки (не привязанные к полям источника данных) и заполнять их данными вручную с помощью события.
- Операции изменения размера и перемещения колонок
- [Меню фильтрации колонок](filter-and-search.md#фильтры-колонок) — вы можете фильтровать данные сетки с помощью раскрывающихся меню, отображающих уникальные значения колонок. Щёлкните кнопку фильтра в заголовке любой колонки, чтобы получить доступ к параметрам фильтрации.
- [Панель поиска](filter-and-search.md#панель-поиска) — помогает пользователю быстро находить строки по содержащимся в них данным.
- [Строка автофильтра](filter-and-search.md#строка-автофильтра) — специальная строка, позволяющая пользователю фильтровать данные по колонкам.
- [Перетаскивание строк](row-drag-and-drop.md) — пользователь может перетаскивать строку в пределах контрола и в другой контрол.
- [Группы колонок](bands.md) — позволяют визуально группировать несколько колонок под общим заголовком.
- [Закреплённые колонки](columns.md#fixed-columns) — позволяют определённым колонкам оставаться видимыми и закреплёнными у левого или правого края сетки, пока другие колонки прокручиваются по горизонтали.
- [Автоподбор ширины](columns.md#best-fit) — эта функция изменяет размер колонок до минимальной ширины, необходимой для полного отображения содержимого колонки (значений и заголовков) без усечения.
- Шаблоны заголовков колонок — позволяют отображать пользовательское содержимое в заголовках колонок, включая изображения.
- Множественное выделение строк (подсветка) — вы можете включить режим множественного выделения строк, позволяющий пользователю выделять (подсвечивать) несколько строк одновременно.
- [Поддержка атрибутов Data Annotation](columns.md#automatic-column-generation) — контрол DataGrid учитывает специальные атрибуты Data Annotation, применённые к свойствам источника данных. Вы можете использовать атрибуты Data Annotation, чтобы задать пользовательскую видимость, позицию, состояние «только для чтения» и отображаемое имя для автоматически создаваемых колонок.
- [Высокая производительность для больших объёмов данных](performance-and-data-virtualization.md) — механизм виртуализации данных для вертикальной и горизонтальной прокрутки повышает производительность контрола при отображении большого количества строк и колонок.
- [Экспорт в форматы XLSX, PDF, CSV и изображения](export.md)
