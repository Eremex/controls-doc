# Производительность и виртуализация данных

Контролы DataGrid и Tree List поддерживают механизм виртуализации данных, который повышает производительность (время загрузки) контрола при работе с большими наборами данных.
Когда виртуализация данных включена (по умолчанию), контрол создаёт визуальные элементы (ячейки, заголовки колонок и т. д.) только для текущей области просмотра. В противном случае визуальные элементы создаются и хранятся в памяти даже для ячеек и заголовков колонок за пределами области просмотра.

## Вертикальная и горизонтальная виртуализация

Вертикальная виртуализация (при прокрутке строк) всегда активна.

Горизонтальная виртуализация (при прокрутке колонок) включена по умолчанию.

##### Связанный API

- Свойство `DataGridControl.AllowHorizontalVirtualization` — получает или задаёт, включена ли горизонтальная виртуализация.


Вам может потребоваться отключить горизонтальную виртуализацию, если строки имеют разную высоту (когда высота строки рассчитывается на основе содержимого ячеек). См. [Автоматическая высота строки](rows.md#автоматическая-высота-строки).

Когда горизонтальная виртуализация включена, автоматическая высота строк рассчитывается на основе содержимого текущих видимых ячеек. Ячейки за пределами области просмотра не влияют на расчёт высоты строки. При прокрутке к ячейкам с другой высотой содержимого высота строки динамически изменяется. Чтобы предотвратить динамическое изменение высоты строк при горизонтальной прокрутке, отключите горизонтальную виртуализацию.

``` xml
<mxdg:DataGridControl x:Name="dataGrid" AllowHorizontalVirtualization="False">
```
