# Часто используемый API

## Свойства

Свойство | Описание 
---|---
`ActiveEditor` | Возвращает активный редактор ячейки Eremex. Свойство возвращает `null`, если в данный момент нет активного редактора или когда в сфокусированной ячейке активен не-Eremex редактор.
`AllowEditing` | Возвращает или задаёт, включены ли операции редактирования ячеек.
`AutoGenerateRows` | Возвращает или задаёт, генерирует ли пустой контрол автоматически строки для всех публичных свойств, доступных в привязанном объекте (объектах), при инициализации контрола. Если контрол уже содержит строки, автоматическая генерация строк отключается. Чтобы вручную заполнить контрол строками, вы можете использовать метод `PopulateRows` или добавлять строки в коллекцию `Rows`.
`CellTemplate`  | Возвращает или задаёт шаблон для отрисовки редакторов во всех ячейках. Вы можете использовать свойство `PropertyGridRow.CellTemplate`, чтобы задать редактор ячейки для конкретных строк.
`FocusedRow` | Возвращает или задаёт сфокусированную строку. Это свойство позволяет сфокусировать конкретную строку.
`Rows` | Возвращает строки контрола, отображаемые на корневом уровне. Для категориальных строк (объектов `PropertyGridCategoryRow`), хранящихся в этой коллекции, вы можете использовать свойство `PropertyGridCategoryRow.Rows`, чтобы обратиться к их дочерним строкам.
`RowsDataTemplates` | Задаёт шаблоны данных, используемые для отрисовки строк из источника строк (свойство `RowsSource`).
`RowsSource` | Задаёт источник данных для генерации строк с помощью шаблонов данных (`RowsDataTemplates`).
`SelectedObject` | Возвращает или задаёт объект, свойства которого отображаются в контроле.
`SelectedObjects` | Возвращает или задаёт список объектов, свойства которых отображаются в контроле.
`UseModernAppearance` | Возвращает или задаёт, отрисовывается ли контрол в стиле `Modern` или `Classic`.

## Методы

Метод | Описание
------|------
`CloseEditor` | Скрывает активный редактор и сохраняет внесённые изменения.
`HideEditor` | Скрывает активный редактор и отменяет внесённые изменения.
`PopulateRows` | Генерирует строки для публичных свойств, предоставляемых привязанным объектом (объектами) (свойства `SelectedObject` и `SelectedObjects`). Перед началом генерации строк существующие строки очищаются.
`PostEditor` | Сохраняет изменения, внесённые в ячейку, в привязанный объект (объекты).
`ShowEditor` | Активирует редактор сфокусированной строки. 

## События

Событие | Описание
------|------
`CellValueChanged` | Возникает при изменении значения ячейки.
`CustomCellTemplateData` | Позволяет предоставить пользовательский объект в качестве значения шаблона ячейки. Дополнительную информацию смотрите в следующем разделе: [Пользовательские редакторы](custom-editors.md#динамическое-назначение-редакторов-на-основе-типа-данных-строки).
`ShowingEditor` | Возникает при активации редактора ячейки.
