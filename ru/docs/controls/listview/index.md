# ListView

`ListViewControl` — это контейнер элементов, который поддерживает различные варианты размещения элементов, сортировку, группировку, фильтрацию и выделение элементов. Вы можете использовать `ListViewControl` для создания интерфейса, как в правой панели Проводника Microsoft Windows.

Задав шаблон элемента, вы можете отрисовывать элементы ListView любым произвольным образом. Например, шаблон может указать ListView отрисовывать элементы в виде значков, значков с текстом или просто текста.

![ListView-svgbrowser](../../images/ListView-svgbrowser.png)

Основные возможности контрола включают:

- Размещение элементов в одну колонку (вертикальный список) или в несколько колонок (с включённым переносом).
- Поддержку паттерна проектирования MVVM — вы можете заполнять контрол элементами из источника элементов.
- Шаблоны элементов позволяют отрисовывать элементы любым произвольным образом.
- Сортировку элементов — вы можете сортировать элементы по любому числу полей (свойств) элементов.
- Группировку элементов — элементы, имеющие одинаковые значения определённых полей (свойств), объединяются в одни группы. Как и при сортировке, вы можете группировать элементы по одному или нескольким полям (свойствам).
- Разворачивание и сворачивание групп.
- Фильтрацию элементов — обработайте специальное событие для фильтрации элементов.
- Два режима выделения элементов: одиночный и множественный.
- Использование клавиатуры для навигации и выделения элементов.

Дополнительную информацию смотрите в следующем разделе: [Обзор контрола ListView](listview-overview.md).
