# Ribbon


`RibbonControl` позволяет создать интерфейс Ribbon (ribbon), вдохновлённый приложениями Microsoft Office. Контрол поддерживает два вида — классический и упрощённый, которые располагают элементы в три и одну строку соответственно. Пользователь может переключаться между ними с помощью специальной кнопки выбора вида.

![ribbon](../../images/ribbon.png)

Основные возможности контрола Ribbon включают:

- Классический и упрощённый виды
- Поддержку всех типов элементов (команд), доступных в [традиционных меню](../toolbars-and-menus/index.md): обычные кнопки, кнопки-флажки, редакторы, надписи, подменю и группы кнопок.
- Встроенные и выпадающие галереи элементов
- Панель быстрого доступа — пользователь может во время работы добавлять на неё часто используемые команды через контекстное меню.
- Настройку положения панели быстрого доступа (над или под командной панелью Ribbon) и её видимости
- Отображение элементов в области заголовков страниц
- Раскраску заголовков страниц (позволяет выделять контекстные вкладки)
- Навигацию по элементам Ribbon с клавиатуры
- Адаптивную компоновку групп и элементов (перестраивает расположение команд и меняет размер отображения элементов Ribbon при изменении ширины контрола Ribbon)
