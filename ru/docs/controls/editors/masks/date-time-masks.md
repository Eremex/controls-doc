# Маски даты и времени

Тип маски `DateTime` позволяет пользователям вводить значения даты-времени в редакторах в соответствии с заданной маской ввода. Маску ввода также можно использовать для форматирования значений даты-времени в режиме отображения (когда редактирование текста не активно). У контрола `DateEditor` тип маски `DateTime` включён по умолчанию. Чтобы включить этот тип маски для других текстовых редакторов, установите свойство редактора `TextEditor.MaskType` в `DateTime`.

Используйте свойство редактора `Mask`, чтобы задать маску ввода. Маска ввода — это строка, определяющая шаблон, по которому значение даты-времени вводится или форматируется.

Текущая культура влияет на большинство масок даты-времени. Например, культура определяет отображаемые названия дней недели и месяцев. Вы можете принудительно назначить маске конкретную культуру с помощью свойства `TextEditor.MaskCulture`.

Редакторы Eremex поддерживают стандартные и пользовательские маски даты-времени.

## Стандартные маски

Стандартные маски даты-времени, поддерживаемые редакторами Eremex, соответствуют наиболее распространённым [стандартным форматам отображения даты и времени](https://learn.microsoft.com/en-us/dotnet/standard/base-types/standard-date-and-time-format-strings), которые вы можете использовать для форматирования значений в .NET. 

### Пример

Следующий пример применяет маску `d` к `DateEditor`. Эта маска форматирует значение редактирования в соответствии с системным шаблоном короткой даты.

``` xml
xmlns:mxe="https://schemas.eremexcontrols.net/avalonia/editors"

<mxe:DateEditor x:Name="DateEditor" Mask="d"/>
```

![dateeditor-mask-d-example](../../../images/dateeditor-mask-d-example.png)

### Стандартные спецификаторы маски

Стандартная маска даты-времени состоит из одного стандартного спецификатора маски. Таблица ниже показывает доступные стандартные спецификаторы маски. 

| Спецификатор маски | Описание | Пример (ru-Ru) |
|---|---|---|
| `d` | Шаблон короткой даты. <br><br> См. свойство `CultureInfo.DateTimeFormat.ShortDatePattern`. | "05.07.2026" |
| `D` | Шаблон длинной даты. <br><br> См. свойство `CultureInfo.DateTimeFormat.LongDatePattern`. | "воскресенье, 5 июля 2026 г." |
| `t` | Шаблон короткого времени. <br><br> См. свойство `CultureInfo.DateTimeFormat.ShortTimePattern`. | "13:05" |
| `T` | Шаблон длинного времени. <br><br> См. свойство `CultureInfo.DateTimeFormat.LongTimePattern`. | "13:05:17" |
| `f` | Полный шаблон даты-времени (короткое время). <br><br> Маска объединяет шаблоны длинной даты и короткого времени, разделённые пробелом.  | "пятница, 23 января 2026 г. 18:15" |
| `F` | Полный шаблон даты-времени (длинное время). <br><br> См. свойство `CultureInfo.DateTimeFormat.FullDateTimePattern`. | "пятница, 23 января 2026 г. 18:15:21" |
| `g` | Общий шаблон даты-времени (короткое время). <br><br> Маска объединяет шаблоны короткой даты и короткого времени, разделённые пробелом. | "30.09.2025 19:35" |
| `G` | Общий шаблон даты-времени (длинное время). <br><br> Маска объединяет шаблоны короткой даты и длинного времени, разделённые пробелом.  | "30.09.2025 19:35:07" |
| `M` или `m` | Шаблон «день месяца». <br><br> См. свойство `CultureInfo.DateTimeFormat.MonthDayPattern`. | "12 августа" |
| `R` или `r` | Шаблон RFC1123. <br><br> См. свойство `CultureInfo.DateTimeFormat.RFC1123Pattern`. | "ср, 12 авг. 2026 06:19:57 GMT" |
| `s` | Сортируемый шаблон даты-времени; соответствует ISO 8601. <br><br> См. свойство `CultureInfo.DateTimeFormat.SortableDateTimePattern`. | "2025-09-18T11:57:33" |
| `u` | Универсальный сортируемый шаблон даты-времени. <br><br> См. свойство `CultureInfo.DateTimeFormat.UniversalSortableDateTimePattern`. | "2025-09-18 11:57:33Z" |
| `Y` или `y` | Шаблон «год месяц». <br><br> См. свойство `CultureInfo.DateTimeFormat.YearMonthPattern`. | "июль 2026 г." |

## Пользовательские маски

Вы можете создавать пользовательские маски, если стандартные маски не соответствуют вашим конкретным потребностям. Пользовательская маска состоит из одного или нескольких пользовательских спецификаторов маски.

### Пример

Следующий пример применяет маску `'DATE:' yyyy MMMM dd, 'TIME:' HH:mm` к `DateEditor`. Эта маска позволяет пользователям вводить части даты и времени значения даты-времени. Маска также отображает статические (только для чтения) строки `DATE` и `TIME`.

![dateeditor-custommask-example](../../../images/dateeditor-custommask-example.png)
