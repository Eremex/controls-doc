# Маски

Маски позволяют ограничивать ввод данных в текстовых редакторах. Их также можно использовать для форматирования значений редактора в режиме отображения (когда редактор не в фокусе).

Чтобы включить ввод с маской, сделайте следующее:

- Установите свойство редактора `TextEditor.MaskType` в тип маски.
- Установите свойство редактора `TextEditor.Mask` в конкретную маску.

Поддерживаются следующие типы масок:

- `Numeric` — режим маски, предназначенный для приёма числовых значений.
- `DateTime` — режим маски, предназначенный для приёма значений даты-времени.

Следующие разделы содержат более подробную информацию о поддерживаемых режимах масок и масках:

- [Числовые маски](numeric-masks.md)
- [Маски даты и времени](date-time-masks.md)

## Использование маски как формата отображения

Маску, заданную свойством `TextEditor.Mask`, можно использовать для форматирования значения редактора в режиме отображения (когда редактирование текста не активно). Эту настройку задаёт свойство `TextEditor.MaskUseAsDisplayFormat`. Значение свойства по умолчанию — `true`.

## Настройки культуры маски

Многие маски зависят от текущей культуры. Например, десятичный разделитель для числовых масок различается в разных культурах. Значения даты-времени форматируются с использованием специфичных для культуры шаблонов и локализованных названий дней недели и месяцев.

Свойство `TextEditor.MaskCulture` позволяет задать культуру, используемую маской. Если это свойство не задано, используется культура приложения по умолчанию.

### Пример 

Следующий код задаёт числовую маску "c" для ввода денежных значений в текстовом редакторе и применяет к маске культуру _китайскую (упрощённую)_.

![texteditor-mask-currency-chinese](../../../images/texteditor-mask-currency-chinese.png)

``` csharp
textEditor1.EditorValue = 12.34567;
textEditor1.MaskType = Eremex.AvaloniaUI.Controls.Editors.MaskType.Numeric;
textEditor1.MaskCulture = new CultureInfo("zh-CN");
textEditor1.Mask = "c";
```
