# Прокрутка и масштабирование в контроле диаграммы

Контрол `CartesianChart` поддерживает операции прокрутки и масштабирования как для всего представления, так и для отдельных осей. Пользователь может масштабировать и прокручивать диаграмму с помощью мыши и клавиатуры. В коде эти операции доступны через специальный API.

## Разрешение операций прокрутки и масштабирования

Операции прокрутки и масштабирования включены по умолчанию. Следующие параметры позволяют отключить эти операции для отдельных осей:

- `Axis.EnableZooming`
- `Axis.EnableScrolling`

``` xml
<mxc:CartesianChart.AxesX>
    <mxc:AxisX ShowTitle="False" EnableScrolling="False" EnableZooming="False" />
</mxc:CartesianChart.AxesX>
```
``` cs
chartControl1.AxesX[0].EnableZooming = false;
```

Минимальные границы масштабирования контрола диаграммы предотвращают слишком сильное уменьшение масштаба, при котором представление становится слишком маленьким. Общие диапазоны осей определяют минимальные границы масштабирования. Чтобы задать общий диапазон оси, используйте свойства `WholeMin` и `WholeMax` объектов `AxisX.Range`/`AxisY.Range`.

``` xml
<mxc:CartesianChart.AxesY>
    <mxc:AxisY ShowTitle="False">
        <mxc:AxisYRange WholeMin="100" WholeMax="200" AutoCorrectWholeRange="False" AlwaysShowZeroLevel="True" />
    </mxc:AxisY>
</mxc:CartesianChart.AxesY>
```

Подробнее см. в разделе [Диапазон значений оси](cartesian-chart.md#диапазон-значений-оси)

## Прокрутка и масштабирование пользователем

### Прокрутка всех осей одновременно 

- Перетащите область диаграммы мышью

    или

- Нажмите Ctrl+СТРЕЛКА для прокрутки с клавиатуры.


### Масштабирование всех осей одновременно 

- Прокрутите колесо мыши над областью диаграммы

    или

- Нажмите Ctrl+«+» для увеличения масштаба и Ctrl+«-» для уменьшения.

![chart-zoom-and-scroll-all-series.gif](../../images/chart-zoom-and-scroll-all-series.gif)

### Прокрутка отдельной оси
- Перетаскивайте мышью в области соответствующей оси. 

### Масштабирование отдельной оси

- Прокрутите колесо мыши в области соответствующей оси.

![chart-zoom-and-scroll-individual-series.gif](../../images/chart-zoom-and-scroll-individual-series.gif)

### Масштабирование в конкретную область

- Нажмите и удерживайте SHIFT в области диаграммы, затем перетащите, чтобы выделить нужный прямоугольник.

### Масштабирование в диапазон значений оси

- Нажмите и удерживайте SHIFT в области оси, затем перетащите, чтобы выделить нужный диапазон.

![chart-zoom-into-rectangle](../../images/chart-zoom-into-rectangle.gif)

## Прокрутка и масштабирование в коде

### Отображение конкретного участка данных

Чтобы увидеть конкретный участок данных в видовом окне контрола, настройте видимый диапазон осей контрола диаграммы. Используйте свойства `VisualMin` и `VisualMax` объектов `AxisX.Range`/`AxisY.Range`, чтобы задать диапазон значений для видового окна.

``` cs
chartControl1.AxesX[0].Range.VisualMin = 10;
chartControl1.AxesX[0].Range.VisualMax = 20;
chartControl1.AxesY[0].Range.VisualMin = -50;
chartControl1.AxesY[0].Range.VisualMax = 50;
```

### Имитация операции прокрутки пользователем в коде

Используйте метод `CartesianChart.Scroll`, чтобы прокрутить данные серий вдоль конкретных осей или всех осей одновременно. Этот метод имитирует операцию прокрутки, выполняемую пользователями.

Сигнатура метода показана ниже:

``` cs
public void Scroll(double deltaX, double deltaY, IEnumerable<Axis>? axes = null)
```

- `deltaX` — задаёт количество пикселей для прокрутки вдоль горизонтальной оси (осей). Положительные значения соответствуют прокрутке вправо; отрицательные значения соответствуют прокрутке влево.
- `deltaY` — задаёт количество пикселей для прокрутки вдоль вертикальной оси (осей). Положительные значения соответствуют прокрутке вверх; отрицательные значения соответствуют прокрутке вниз.
- `axes` — оси, вдоль которых прокручивается видовое окно. Если этот параметр опущен, видовое окно прокручивается вдоль всех осей одновременно.

``` cs
//Scroll along all X axes horizontally by 10 units
chartControl1.Scroll(10, 0);

//Scroll along all Y axes vertically by 10 units
chartControl1.Scroll(0, 10);

//Scroll along the first X axis
AxisX axisX = chartControl1.AxesX[0];
chartControl1.Scroll(10, 0, new[] { axisX });
```

### Имитация операции масштабирования пользователем в коде

Используйте метод `CartesianChart.Zoom`, чтобы масштабировать данные серий вдоль конкретных осей или всех осей одновременно. Этот метод имитирует операции масштабирования, выполняемые пользователями.

Сигнатура метода показана ниже:

``` cs
public void Zoom(double delta, IEnumerable<Axis>? axes = null)
```

- `delta` — задаёт количество действий прокрутки колеса мыши вверх/вниз. Это значение определяет коэффициент масштабирования. 
    - Положительные значения соответствуют операциям прокрутки колеса мыши вверх (увеличение масштаба). Значение `1` соответствует одному действию прокрутки вверх. 
    - Отрицательные значения соответствуют операциям прокрутки колеса мыши вниз (уменьшение масштаба). Значение `-1` соответствует одному действию прокрутки вниз. 
    
- `axes` — оси, вдоль которых масштабируется видовое окно. Если этот параметр опущен, видовое окно масштабируется вдоль всех осей одновременно.

``` cs
//Zoom in (imitate a single scroll up action)
chartControl1.Zoom(1);

//Zoom out (imitate a single scroll down action)
chartControl1.Zoom(-1);
```
