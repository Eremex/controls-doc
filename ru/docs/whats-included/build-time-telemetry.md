# Телеметрия во время сборки


Для управления развитием библиотеки Eremex Controls процесс сборки настроен на сбор неперсональных данных во время сборки. Эта телеметрия даёт представление о том, как библиотека Eremex Controls используется при разработке, помогая нам создавать более качественный и стабильный продукт.

## Когда собираются данные

- Телеметрия собирается, когда вы собираете проект, использующий библиотеку Eremex Controls.
- Телеметрия НЕ собирается, когда запускается приложение, использующее библиотеку Eremex Controls.


## Собираемая информация

Данные телеметрии включают:

- TimeStamp — дата и время, когда произошло событие сборки.
- Machine — уникальный идентификатор машины, создаваемый движком телеметрии. Этот идентификатор не основан на вашем IP- или MAC-адресе.
- HasEmxLicense — указывает, существует ли лицензия на библиотеку EMX Controls.
- EmxLicenseExpirationDate — дата истечения срока действия текущей лицензии на библиотеку EMX Controls.
- EMXControlsVersion — версия библиотеки EMX Controls.
- ProjectRootHash — хеш-код, вычисленный на основе имени проекта. Восстановить имена проектов из этих хеш-кодов невозможно.
- Ide — название IDE.
- CiProvider — название CI-системы.
- OutputType — тип приложения.
- TFM — Target framework moniker. Примеры TFM: "net9.0" и "net8.0".
- RID — Runtime identifier. Значения RID используются для идентификации целевых платформ, на которых запускается приложение. Примеры RID: linux-x64, win-x64 или osx-x64. 
- AvaloniaMainPackageVersion — версия пакета Avalonia.
- OSDescription — название и версия ОС.
- ProcessorArchitecture — название архитектуры процессора.

Данные телеметрии не включают персональную информацию, такую как имя пользователя, адрес электронной почты, IP-адрес, MAC-адрес, имена проектов, имена файлов/каталогов или любую часть вашего кода. 

## Как отказаться

Оставляя телеметрию включённой, вы предоставляете анонимные данные, которые помогают нам принимать обоснованные решения о реальных средах сборки. Разрешение на этот сбор данных — самый простой способ внести вклад в развитие продукта.

Однако если вы решите отключить телеметрию, установите переменную окружения EMX_TELEMETRY_OPTOUT в значение 1 или true.
