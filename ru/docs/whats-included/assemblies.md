# Сборки

В этом разделе описаны сборки с контролами и [визуальными темами](../controls/themes/index.md), входящие в библиотеку Eremex Avalonia UI Controls.



## NuGet-пакеты

Сборки и шаблоны проектов Eremex распространяются в виде NuGet-пакетов. Вы можете найти и загрузить их с сайта [nuget.org](https://www.nuget.org) по ссылке ниже:

- [Eremex Controls at NuGet.org](https://www.nuget.org/profiles/EremexControls)

## Включённые сборки

- **Eremex.Avalonia.Controls** — содержит контролы Eremex для форматирования и редактирования данных, а также общие вспомогательные классы. Основные контролы в этой сборке:

    - `DataGridControl`
    - `TreeListControl` и `TreeViewControl`
    - `PropertyGridControl`
    - `ListViewControl`
    - `CartesianChart`, `PolarChart` и `SmithChart`
    - `RibbonControl`
    - `ToolbarManager`
    - `DockManager`
    - `Heatmap`
    - Редакторы данных (`TextEditor`, `ButtonEditor`, `ComboBoxEditor`, `CheckEditor`, `SpinEditor` и другие)
    - Вспомогательные контролы (`MxTabControl`, `MxMessageBox`, `SplitContainerControl`, `CalendarControl` и другие)

- **Eremex.Avalonia.Controls3D** — включает контролы и классы для отрисовки 3D-моделей в ваших приложениях. 
    - `Graphics3DControl` — основной контрол в этой библиотеке, позволяющий отображать 3D-модели и взаимодействовать с ними.

- **Eremex.DocumentProcessing** — библиотека невизуальных компонентов для генерации документов PDF и XLSX.

- **Eremex.Avalonia.Themes.DeltaDesign** — содержит визуальную тему «DeltaDesign» для контролов Eremex.

- **Eremex.Avalonia.Templates** — содержит шаблоны для создания новых проектов Avalonia UI с контролами Eremex с нуля. См. [Шаблоны проектов](project-templates.md).

- **Eremex.Common.Contracts** — содержит общие интерфейсы и базовые классы уровня Model без зависимостей от UI.
