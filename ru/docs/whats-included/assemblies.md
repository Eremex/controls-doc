# Сборки

В этом разделе описаны сборки с контролами и [визуальными темами](../controls/themes/index.md), входящие в библиотеку Eremex Avalonia UI Controls.



## NuGet-пакеты

Сборки и шаблоны проектов Eremex распространяются в виде NuGet-пакетов. Вы можете найти и загрузить их с сайта [nuget.org](https://www.nuget.org) по ссылке ниже:

- [Eremex Controls at NuGet.org](https://www.nuget.org/profiles/EremexControls)

## Включённые сборки

- **Eremex.Avalonia.Controls** — содержит контролы Eremex для форматирования и редактирования данных, а также общие вспомогательные классы. Основные контролы в этой сборке:

    - [`DataGridControl`](../API/Eremex.AvaloniaUI.Controls.DataGrid/DataGridControl.md)
    - [`TreeListControl`](../API/Eremex.AvaloniaUI.Controls.TreeList/TreeListControl.md) и [`TreeViewControl`](../API/Eremex.AvaloniaUI.Controls.TreeList/TreeViewControl.md)
    - [`PropertyGridControl`](../API/Eremex.AvaloniaUI.Controls.PropertyGrid/PropertyGridControl.md)
    - `ListViewControl`
    - [`CartesianChart`](../API/Eremex.AvaloniaUI.Charts/CartesianChart.md), [`PolarChart`](../API/Eremex.AvaloniaUI.Charts/PolarChart.md) и [`SmithChart`](../API/Eremex.AvaloniaUI.Charts/SmithChart.md)
    - [`RibbonControl`](../API/Eremex.AvaloniaUI.Controls.Ribbon/RibbonControl.md)
    - [`ToolbarManager`](../API/Eremex.AvaloniaUI.Controls.Bars/ToolbarManager.md)
    - [`DockManager`](../API/Eremex.AvaloniaUI.Controls.Docking/DockManager.md)
    - [`Heatmap`](../API/Eremex.AvaloniaUI.Charts/Heatmap.md)
    - Редакторы данных ([`TextEditor`](../API/Eremex.AvaloniaUI.Controls.Editors/TextEditor.md), [`ButtonEditor`](../API/Eremex.AvaloniaUI.Controls.Editors/ButtonEditor.md), [`ComboBoxEditor`](../API/Eremex.AvaloniaUI.Controls.Editors/ComboBoxEditor.md), [`CheckEditor`](../API/Eremex.AvaloniaUI.Controls.Editors/CheckEditor.md), [`SpinEditor`](../API/Eremex.AvaloniaUI.Controls.Editors/SpinEditor.md) и другие)
    - Вспомогательные контролы (`MxTabControl`, `MxMessageBox`, [`SplitContainerControl`](../API/Eremex.AvaloniaUI.Controls.Editors/SplitContainerControl.md), [`CalendarControl`](../API/Eremex.AvaloniaUI.Controls.Editors/CalendarControl.md) и другие)

- **Eremex.Avalonia.Controls3D** — включает контролы и классы для отрисовки 3D-моделей в ваших приложениях. 
    - [`Graphics3DControl`](../API/Eremex.AvaloniaUI.Controls3D/Graphics3DControl.md) — основной контрол в этой библиотеке, позволяющий отображать 3D-модели и взаимодействовать с ними.

- **Eremex.DocumentProcessing** — библиотека невизуальных компонентов для генерации документов PDF и XLSX.

- **Eremex.Avalonia.Themes.DeltaDesign** — содержит визуальную тему «DeltaDesign» для контролов Eremex.

- **Eremex.Avalonia.Templates** — содержит шаблоны для создания новых проектов Avalonia UI с контролами Eremex с нуля. См. [Шаблоны проектов](project-templates.md).

- **Eremex.Common.Contracts** — содержит общие интерфейсы и базовые классы уровня Model без зависимостей от UI.
